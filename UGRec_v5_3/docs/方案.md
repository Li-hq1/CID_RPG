# v5_3：下一物品排序与未来目标覆盖

基础代码从 v5_1 物理复制，复用其 AE、HSTU、速度网络、优化器与 checkpoint 机制；没有运行时跨版本导入。旧 v5/v5_1/v5_2 与公共 cache 只读。

## 问题、假设与边界

保留标准 LOO 研究，另加未来多目标实验，检验 FM 是否改善固定 K 下的真实未来覆盖。下一物品 CE 与未来分布监督按任务分工，不以不同损失或样本分散本身证明互补。

future_window 为逐用户连续区间划分：完整原序列最后 h 项预留 test，在 ID 映射前剔除；之前 h 项为 validation，剩余为 train。至少保留两个训练物品。该协议不是全局时间划分，也不是 ComiRec 的用户不相交协议；不声称复现其公开分数。LOO 模式依旧剔除最后一项，倒数第二项验证。历史上限 50，不过滤历史物品，目录 1..N、padding=0。目录文本和 ID 映射按原来的固定全目录约定，AE 统计量只拟合新训练物品。

训练沿 v5_1 首窗全部后继、后续窗只监督末位的规则；每个监督位置额外记录其训练期内的完整 h 步未来。next CE 保留所有下一物品监督；所有辅助项只使用具有完整未来窗口的位置，B/C/D 的辅助位置相同。尾部不补齐、不跨 validation 边界。未来标签按交互次数等权，评价按去重物品集合计算，并单独报告各未来步长指标。

## 统一骨干与有限对照

- A/ce：next CE，无辅助损失，next 排序头读出。
- B/next_fm：next CE + 下一物品 CFM，FM 读出。
- C/future_ce：next CE + 未来分布 CE，独立确定性未来头读出。
- D/future_fm：next CE + 未来物品 CFM，FM 读出。

所有模型构建同一套模块，保持初始化相同；未使用模块不产生有效梯度，参数总数相同不等于有效容量相同。C 的未来头为单线性，与 FM 速度网络容量不同；若 D 超过 C，正式阶段需多兴趣/容量对照，不能据此声称排除了全部容量解释。

CFM 使用连续 t∈[0,1]、源1→目标0：b=sg(normalize(rank(h))*sqrt(d))+ε，c=sg(z_y)，x_t=(1-t)c+tb，u=b-c，L_CFM=mean((v(x_t,t,h)-u)^2)。D 从同一历史未来 h 项随机抽一个终点，B 用下一项。没有未来均值终点，没有生成端 CE。推理同一源分布，反向 Euler 默认4步、32样本，先计算每样本全目录 softmax，再在概率空间平均，不平均 embedding。

next CE 更新 AE/历史/排序头；辅助项单独使用 ae_grad=False 的历史图，允许 HSTU/条件投影接受梯度，不更新 AE。C 的目录键停止梯度；CFM 的源、终点、桥与标签均停止梯度。共享表征随 CE 改变，联合裁剪也会耦合，不声称完全隔离。

目录≤20000精确 CE，否则4096个均匀有放回负样本的修正近似；辅助 CE 将完整已知未来正例的质量精确加入分母，再用排除这些正例的均匀采样估计其余质量。重复正例仅在分母计一次。最终评测均全目录，不做 sampled evaluation。报告近似分母的 log 不是无偏估计。

## 指标、选模和成本

固定预测时点一次输出 K 个不同物品。多正例 Recall@5/10 和 NDCG@5/10 为主要指标；固定子集 seed20261028，按 NDCG@10 选模；同时记录每个未来步长指标和 CE 头诊断。暂不把无类别的命中覆盖宣称为多样性证明。

默认 seed2024、40epoch、batch256、最多1024监督位置、AE batch512、默认v5_1模型宽度。FM默认32×4=128次速度调用；CE为0。比较固定列表大小，另列实际时间、参数与NFE；不伪装等推理成本。工程检查保留完整模型，只减少batch/监督数/更新数/验证人数，标记 engineering_check=true。

LOO旧生成边缘似然的复现入口为 loo_run.py + configs/legacy_control.json；新纯CE/CFM也可以切换 experiment.protocol=leave_one_out。旧方案复现与新A/B是不同方法，不混合解释。
