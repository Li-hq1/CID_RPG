# v5_3 Beauty 三目标初步实验分析

日期：2026-11-08（用户本地）。本轮是新协议下seed2024的validation探索，完整validation包含4096名选模用户；未访问test，没有多种子。不把它写成稳定优势或所有FM方法的结论。

## 研究问题与执行

保留旧LOO路径，同时检验两层假设：当前next-item CFM是否只因单目标评价而失去收益；增加未来监督后CFM是否比同信息的CE更有效。基础代码来自v5_1的独立副本，使用新纯CE/CFM训练实现，不把旧边缘似然训练误称为CFM。

A/B先运行并审计，B不优于A且不优于自身先验后，依预注册补C/D。所有正式run均40epoch、1760更新、相同8300用户/数据/源码/初始模型/4096选模用户，配置仅arm及run id不同；比较器检查通过。完整模型4272016参数；总参数相同不等于有效容量相同。未扫描种子、窗口、权重、噪声或积分预算。

## 可以支持的判断

1. B对A的多目标NDCG变化-18.26%，且B的FM .04736582低于其未运输先验.05267690。仅换成多目标评价，没有显出当前next CFM优势。不能据此把过去失败完全归因于LOO。
2. C对A的多目标NDCG变化+6.31%，Recall变化+7.76%；第1步NDCG变化-3.16%，第2/3步为+14.03%/+18.10%。未来监督有正向覆盖趋势，同时出现近期相关性的取舍。这不是旧LOO协议上的涨跌，不能替代原LOO实验。
3. D对C的多目标NDCG变化-25.29%，对B为-2.82%。D未优于同未来标签的确定性CE，也低于其自身未运输先验.05504900。当前没有支持FM独立贡献的正向证据。
4. C的next排序头为.05870950，D的next排序头为.05500090，都是各自辅助读出选模checkpoint的诊断，没有独立按CE选模，不能与独立CE选模主表冒充等价比较。

## 数据和机制限制

- Beauty原始22363人中保留8300人（37.1%）；每人最后3项预留test、之前3项validation。仅按长度和训练/验证区间审计，不映射test目标。该人群与旧全用户LOO不同。
- 训练11210窗口、60506个next位置、45717个完整未来辅助位置；8300人中5123人能提供完整h3训练窗口，3177人只贡献next CE。训练长度中位数5；这是当前数据的多目标监督限制，不据本轮结果临时改筛选。
- 逐用户连续时间顺序划分，不是全局时间切分，也不是ComiRec用户不相交协议；固定全目录文本/ID信息约定，AE统计只用新train物品。
- C未来头与D速度网络有效容量和解码不同；FM桥、表示、优化或解码仍可能有局限。本轮不能证明所有FM无效，也不能单凭MSE下降声称拟合已充分。
- FM32样本×4步，128个速度调用/用户；CE为0。共享GPU4且C/D运行存在重叠，记录的墙钟时间不用于独占速度排名。A保留用于匹配训练RNG的辅助历史计算，不能拿其耗时代表最精简CE部署。

## 当前取舍

v5_3基础设施、LOO保留和多目标四组初筛已完成。研究假设目前只获得“未来监督有助于覆盖”的单种子趋势，未获得FM独立价值。保留原始结果，不开启更大调参矩阵或多种子扫描。若继续FM，应先提出并验证一个针对场拟合、训练目标表示或解码的具体机制假设；不能仅为论文保留FM而把它写成已证实贡献。下一数据集应按任务和数据适配性选择，不能按是否出现正收益选择。
