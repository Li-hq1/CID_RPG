# UGRec_v2 方案：几何保持压缩与两阶段训练

> 本文于 2026-10-28 依据现有实现整理。v1 的条件生成、因果监督和多次采样设计在本版独立保留；本阶段新增的研究变量是压缩器。

## 动机与假设

PCA 是固定线性压缩。为了后续向类似 REPA-E 的统一表示/生成训练推进，需要先建立可学习、可独立诊断且能保持物品内容几何的压缩模块。

假设 AE 可以在重建语义内容的同时维持适合 RF 学习与物品检索的低维空间。当前已有观察是 AE 与 PCA 推荐效果接近；本阶段价值同时包括搭建可联合优化的表示模块，不能仅以“可学习”推定推荐更优。

## 表示与结构

输入为冻结的 Qwen3 2560 维内容 embedding。默认编码器 `2560→1024→512→128`，GELU 激活，解码器反向重建；不使用 BatchNorm、dropout、KL 或 VAE 双分支。保留线性 AE 作为诊断模型。

输入均值和一个全局 RMS scale 仅在压缩训练子集上拟合。压缩验证/测试集从推荐训练物品中固定抽取，不能使用推荐测试目标拟合统计或关系 teacher。对样本量的消融仅截取压缩训练集，保持验证/测试集不变。

## 几何目标

```text
z = Eφ(normalize_input(e))
e_hat = Dψ(z)
L_AE = L_normalized_MSE + 0.1 L_cosine
     + λ_var L_variance + λ_corr L_off_diagonal_correlation
     + λ_rel L_relation_KL
```

默认 variance/correlation/relation 权重分别为 0.1/1.0/0.1，关系温度 0.1。重建和 cosine 始终启用；几何项先 warmup 10 epochs，再在 20 epochs 内线性增加。记录各项 encoder 梯度范数、有效秩、重建和邻域指标，防止压缩维度塌缩。

关系策略有三种：`none` 关闭关系蒸馏；`batch` 让 batch 内 latent 相似度匹配原内容相似度；`local` 使用训练物品构成的近邻/中距离/随机候选软分布。teacher 只使用内容特征，不使用行为测试标签。当前代码默认 none；batch/local 的效果必须通过相同推荐评估协议检验。

## 两阶段训练与 artifact 协议

1. 独立训练 AE，以压缩验证指标选择 best，导出全部物品 latent。
2. 用推荐训练物品计算 latent 的逐维均值/标准差，生成固定推荐特征。
3. 冻结特征，按 v1 方式训练 Transformer/HSTU + RF；AE 不接受推荐训练梯度。
4. 评估时使用同一 artifact 物品库，多次采样并聚合候选。

artifact 保存 AE best、物品划分、原始与标准化 latent、统计、loss、几何诊断及 manifest。源信息包含内容向量哈希、item 顺序、训练物品 mask 与文本编码设置；文件哈希构成 artifact ID。推荐 checkpoint 同时记录压缩方法和 artifact ID。

早期 batch artifact 的配置不包含 `relation_mode`；读取时显式按 batch 解释，保持旧指纹不变。独立 AE 输出属于本版，不将新权重写回公共原始数据目录。

## 实验设计与判据

| 比较 | 目的 |
| --- | --- |
| PCA / 线性 AE / MLP AE | 区分优化、非线性容量与表示变换 |
| none / batch / local relation | 判断内容关系保持是否帮助检索与 RF |
| 去 variance / 去 correlation | 诊断塌缩约束的作用 |
| 相同推荐主干、监督与采样预算 | 隔离压缩模块的贡献 |

先比较压缩 held-out 重建、邻域、有效秩；再比较正式推荐 recall/ndcg 与生成成本。压缩指标更好不自动意味着推荐更好。研究者已有观察：两种压缩总体接近，关系约束在部分实验中有帮助；本次仅整理已有文件，没有产生新的效果结论。
