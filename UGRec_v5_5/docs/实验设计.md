# 干净端点联合监督实验（2026-11-08，本地日期）

## 问题、假设与适配

v5 control 没有显式 FM 回归项。此前分开历史CE与速度MSE、或加入Prior/CFM/Align，未能回答：同一干净物品输出的连续回归和目录排序是否能互补。假设是连续目标提供物品几何约束，CE保留物品可分性；二者语义目标相同，但梯度、尺度与最优点不必完全一致。

文献依据：FMRec，IJCAI 2025，https://www.ijcai.org/proceedings/2025/0346.pdf ，式13和17–18，同一个f预测可学习物品向量并参与目录CE。本版仅适配此机制；不移植输入扰动、历史重构分支及其额外MSE。既有AE几何项始终保留。

## 定义与梯度

保持 v5 control 的全部参数形状及初始化：AE内容2560→512→256→128，物品 `z=LN(AE(content))`，两层HSTU、条件投影、两块宽256网络和可学习历史锚点。与v5_1已采用的一层HSTU不混用，避免结构因素混入本次损失对比。

```text
b = sqrt(d)*normalize(anchor(h)) + epsilon, epsilon ~ N(0,I)
s ~ uniform{0,...,999}/999        # s=1是源，s=0是数据
x_s = (1-s)*z_y + s*b
xhat = f_theta(x_s, s, h)        # 网络输出直接解释为干净物品
L_FM = mean_batch,draw,coordinate[(xhat-z_y)^2]
L_CE = mean_batch,draw[CE(cos(xhat,Z)/0.07, y)]
L_total = c*L_CE + lambda*L_FM + 0.1*L_AE
```

两个损失、目标端点、目录键和历史都不detach，与control同为端到端优化；因此MSE可能也改变表示，应记录目录方差和目录平均方向。FM是干净端点参数化下的回归目标，不声称与不加权速度MSE逐时刻相等：v=(x_s-f)/s，相应速度误差是端点误差/s，s=0不做速度换算。MSE按维平均，不能照搬论文sum维度下的权重。

新方案训练每位置8个桥样本，各自CE；control则是8噪声在源端一步运输后的边缘CE。桥训练与逐样本聚合是本次适配的明确变化，其影响通过相同新方案的CE-only以及必要的源端CE-only诊断解释。推理均32个源样本、完整目录概率混合，一步时直接取f(b,1,h)。多步诊断使用v=(x-f)/s的Euler，避免s=0除法；只在固定selection检查，不根据全量validation调积分步数。

## 预注册对照与有界探索

先仅 Beauty/seed2024：control重训；桥上CE-only（c=1,lambda=0）；桥上联合（c=1,lambda=1）。CE-only与联合除权重外完全一致，是FM增量的主要对照。均40epoch、batch256、每批最多1024监督位置、训练draws8，4040更新，固定4096用户每5轮选模，按部署推理NDCG@10选checkpoint。完整22363用户validation仅做锁定checkpoint审计；不评test。保留每组初始状态和数据/selection指纹，确认可比。

初轮后按selection及原始/加权loss决定有限尝试：FM造成退化则尝试lambda=0.1；FM有益或其影响很弱时尝试lambda=5。最多两个额外权重，不做笛卡尔积、不改训练预算。如果桥上CE很小但部署明显低于control，补源端CE-only，判断目标泄漏式去噪捷径与部署分布差异；如果需要确认CE防坍缩作用，可补FM-only。每项执行前记录具体证据与假设。

## 核验与取舍

单种子只表述趋势。先看匹配CE-only的FM增量，再看是否达到原control；NLL、桥上MSE或Recall不替代主指标。不因“真值同一物品”直接断言损失相容或必然提升。正式运行保存resolved config、源码快照和SHA256、初态hash、训练数据和selection hash、逐轮loss、checkpoint、完整排序与重载精确检查。工程smoke不算benchmark。旧版保护hash保存在 protected_versions.json。
