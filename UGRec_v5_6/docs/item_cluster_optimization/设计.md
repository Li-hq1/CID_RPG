# 尺度匹配正收益上的有限优化

当前目标是改善直接 CE 推荐排序，检验尺度匹配后的 VLAD 表示变换是否还有可扩展收益，以及多簇是否能保留有用的互补信息。固定参考为上一轮 scaled K1/G2：selection NDCG10=.06288856，完整审计=.06197726；原无VLAD baseline为 .06181346/.06056862。不得根据后续结果漂移参考。

探索仍为Beauty/seed2024，各40epoch/4040更新/batch256、两层HSTU、D128、rec LR=.001、AE LR=.0001、CE+.1AE。AE/catalog保持原单向量，所有VLAD token归一化后乘sqrt(128)。同item原RoPE、item内连接、item间因果与展开长度注意力分母不变。固定4096人selection每5轮选模，完整22363 validation只审计已选checkpoint，无test/多种子/自动搜索。

## 阶段P：参数取舍

先运行3组：K1/G1、K1/G4、K2/G2。K1/G2和K4/G2已有完整结果。前两组回答单token表示变换需要多少组派生特征，K2补充多簇的最小非平凡邻域。实现限制expansion=G以维持128维，因此G也改变展开容量和参数量，不能当作纯分组数消融。K1分配softmax恒为1，其分配参数梯度为0是结构事实，不要求无意义的非零梯度。

阶段P后依据selection登记决策，只有G1或G4有更好证据才补该G下K2；如选G4且K2呈积极趋势，可再补K4/G4检验簇数与组数关系。不得机械执行完整K×G网格；不因full audit更好回选epoch。单种子小差别作为趋势，不能称稳定最优超参。

## 阶段A：处理等权聚合的信息损失

聚合对照固定一个有证据的多簇sum配置，同参数初态、token尺度、训练与优化器。若所有多簇参数组仍弱，使用最有竞争力的已测多簇组检验聚合瓶颈；不将未超过正收益K1的候选当作最终改善。

1. mass聚合：逐簇L2归一化消除了原始VLAD幅度，各簇等权相加忽略了激活质量差异。令pi_k=m_k/sum(m)，HSTU后以K*sum(pi_k*h_k)聚合。无新参数、不detach质量；K倍使均匀权重与sum初态尺度一致，后续原LN不变。它检验现有分配质量能否提供更好的融合权重，不将mass当作已证实的置信度。
2. context聚合：由共享评分q^T LN(h_k)得到softmax权重，以K*sum(pi_k*h_k)聚合。q为128维零初始化参数，从等权sum开始；无簇ID、额外MLP、门控或新loss，rec优化器更新q。每个item只使用自身上下文化簇状态，保持因果和簇置换不变。它检验历史相关的选择是否优于固定等权/内容mass，不能把权重解释成已验证的语义重要性。

两种聚合互斥，不把mass先验叠加到context。K1下均退化为单token读出；sum与mean的LN尺度等价不再训练。此处改变HSTU后的聚合，与上一轮AE decoder/catalog前的concat-linear融合不同。

参考机制：NeXtVLAD分组来自arXiv:1811.05014（CVF原论文）；学习置换不变的实例聚合参考Ilse等ICML2018，arXiv:1802.04712。这里采用简化共享线性评分，不声称复现原论文的完整MIL网络。

## 验收和后续取舍

源码冻结于history/before_item_cluster_optimization；上一轮全部输出、源码快照与图表登记hash，禁止覆盖。每组运行保存自身实际源码、展开配置、数据、初态、selection、逐用户预测。阶段间允许源码演进，但同一聚合对照的共同初始参数和tokenizer应一致。若sum参考与新聚合处于不同源码阶段，必须验证默认sum兼容性和完整共同参数hash，而非声称源码逐位相同。

新聚合需验证公式、uniform初态、K1等价、置换不变、未来/padding隔离、推荐loss到tokenizer/评分器的梯度、优化器归属、精确恢复下一更新；真实缓存完整宽度4更新及重载通过后正式训练。工程测试不冒充benchmark。

所有阶段记录selection/full NDCG/Recall/NLL、训练CE、参数/显存、token范数、簇方向差异、分配/聚合熵和权重是否实际偏离等权。重载预测和指标重算审计旧/新结果。G改变的新增参数初态不可能全部相同，只要求共享AE/HSTU/投影/头；聚合比较的tokenizer必须相同。无多种子稳定性结论，最终方法确定后才另行验证。


## 阶段S：由阶段P负结果触发的有限尺度邻域

阶段P三组均未超过固定K1/G2正收益参考，停止扩大K/G。依据已确认的输入尺度效应，在正收益K1/G2上仅补固定倍率.5/2两组，即范数sqrt(128)/2、2sqrt(128)，与原sqrt(128)构成邻域。它检验HSTU输入残差与内部归一化更新分支的相对强度，不同时改变池化、学习率或参数量。这里是对尺度的受控干预，不声称所有优化方法都必须固定sqrt(128)。每组整个模型初态与原scaled K1应完全相同。

阶段S和聚合阶段A独立：聚合仍固定sqrt(128)，避免同时调尺度与聚合。只增加这两个倍率，不沿结果继续扩大尺度网格。记录启动前决策decision_S_start.json；无论结果正负，本轮均在必要审计与机制检查后收尾，不自动扩温度/LR/数据集/种子。
