## 阶段D：逐级残差和正交监督的设计约束（待机制定义后冻结）

瓶颈是当前normalize(x-c_k)的多个token接近同向，不是梯度中断或尺度失配。逐级减去全局中心r_k=r_(k-1)-c_k，仍只是x减去累计偏移，不能自动保证内容分解。VQ/RQ需要区分每级解释出的贡献q_k与剩余r_k，不能把二者混用。原RQ论文CVPR2022 Lee等《Autoregressive Image Generation Using Residual Quantization》以r_d=r_(d-1)-e_(k_d)递推；若采用连续分解，应清楚说明不是真正离散RQ-VAE，不额外叠加码本/commitment等损失。

正交监督优先约束实际送入HSTU的逐item token方向，而不是只约束中心矩阵。目标为有效位置的平均非对角cos²，正负同向都应惩罚；padding剔除，K1退化为0。和改变分解结构分开，不首轮组合两条路线。保持任务信息和最终尺度，记录正交项及其对token模块/共享backbone的梯度、近零token与每级原始能量，避免把方向不同等同于语义互补。

差异探索默认seed2024。最终实现与最小对照组须在运行前追加本文件并登记决策；不因短程梯度非零直接声称有效。根据selection推进有限消融，不自动枚举loss权重或模块组合。


## 阶段D已确认：连续内容分解与单独正交约束

用户确认采用连续残差分解，而非离散量化或每次全局减中心。固定K4和共享linear映射，三个新候选均seed2024，只训练一次：

1. **sequential_k4_linear**：r0=x；第j=1..3级有D×32可学习子空间基U_j，经reduced QR得到正交列Q_j；q_j=Q_j Q_j^T r_(j-1)，r_j=r_(j-1)-q_j。第4个贡献q4=r3，保留剩余内容；raw贡献和严格为x（浮点容差）。每步提取依赖当前剩余量，正交投影使该步剩余能量不增加。它不保证不同级最终贡献两两正交，不宣称语义粗细层级已经形成。无额外重建/commitment/码本loss。
2. **parallel_k4_linear**：相同U_j、相同参数和初始化，q_j=Q_j Q_j^T x，第4个为x-Σq_j。它与逐级版本都保留raw总内容，但不逐步扣除已解释部分，是必要同容量对照；不能把较原中心bank的差异全归因为递推。U初态来自固定局部generator(seed0)的正交全基不同32列，不消耗全局RNG，两方案初态函数在数值容差内相同。
3. **orth_k4_linear**：沿用原轻量中心残差K4+linear的全部结构和初态，只在实际HSTU输入方向上加平均非对角cos²。L=L_CE+.1L_AE+lambda*L_orth；每个有效item位置等权，剔除padding，无额外centers正交或多样性loss，不与逐级分解组合。lambda不扫参：用seed2024首个固定训练batch、初始化中心参数上的梯度范数，令lambda*||grad_centers Lorth||=||grad_centers LCE||，一次确定后全程固定；校准不读validation，不更新任何参数。记录实际lambda与梯度，CE/orth梯度分开测量。其初始cos接近1而loss梯度较小，避免仅凭loss量级选极弱的系数。

两种分解各有3*128*32=12288子空间参数，加共享W16384，共28672；对照彼此容量一致，但不与原中心bank16896等容量。每个raw贡献经过共享W，再规范到sqrt(128)进入原HSTU。归一化后不再宣称token之和严格等于原x；保内容恒等式仅指raw分解。保持原item共享RoPE、item-block因果、最终sum与原训练配置。

真实cache短程要验证QR梯度、逐级能量关系、raw重构、非零贡献、尺度及精确恢复。观察每级raw能量份额和近零比例，防止归一化放大无意义余量；同时记录簇间方向、跨item方差/均值，不能把全局常数簇变得正交当作有用分工。首轮不同时加入正交到分解，不扫lambda/rank/K/LR；上述三组完成后审计收尾，用户已请求的两个候选多种子另行如实汇总。
