# 原control的生成路径是否提供净收益

## 唯一问题

用户明确放弃上一轮FM+CE损失路线，本轮只判断：在原control骨干及训练协议下，保留生成分支是否优于直接用历史表示进行物品CE预测。此前v5_4 Prior-only提供Beauty上直接CE的支持性线索，但仍保留未用FM模块；本轮用实际删除模块的匹配对照判断，不把旧分数充作新测量。

## 两组定义

共同部分：原v5 control内容AE2560→512→256→128，物品z=LN(AE(content))，HSTU两层宽128，原条件投影c=Linear(LN(h))与原输出头a=Linear(c)，cosine/T=.07，AE几何项权重.1，所有推荐路径端到端更新AE。只有必要输出投影，不额外增加MLP或ID分类参数。

```text
control:
  b_s = sqrt(d)*normalize(a) + epsilon_s
  g_s = b_s - v_theta(b_s, 1, c)
  L_rec = -log mean_{s=1..8} softmax(cos(g_s,Z)/T)_y
  inference: 32个源样本的概率混合，一步生成
direct CE:
  q = a
  L_rec = CE(cos(q,Z)/T,y)
  inference: 1个确定性查询，0次FM前向
both:
  L_total = L_rec + .1*L_AE
```

原control没有显式FM回归loss，所以结论针对生成路径的整体净作用，不能称作“去掉速度MSE的效果”。目录≤20000完整CE，超过则同一4096均匀修正抽样，验证始终完整目录，不改变过滤。直接组删除噪声和概率混合是删除生成路径本身的必要部分，计算量因此降低，不冒充等FLOPs比较，也不通过额外训练来补算力。

## 初始化与实际删除

控制组按原构造顺序初始化。直接组在CPU构造阶段镜像同一顺序，取得完全相同的AE/HSTU/投影/输出头初值后立即释放临时FM对象和无条件参数；在移动设备、创建优化器和checkpoint之前，模型中已经没有diffloss或uncond_condition参数。该一次性CPU初始化不是保留未用FM模型；须测试模型、优化器、checkpoint与实际前向都无FM路径。两组共享初态hash必须相同，全模型hash因参数集合不同而不同。

删除噪声采样后训练随机数消费自然不同，因此不声称每次dropout完全逐步一致。固定seed、数据加载顺序、共享初始化和训练协议；小幅差异只作单种子趋势。

## 最小实验范围

Beauty、Sports_and_Outdoors、Toys_and_Games分别只跑control/direct CE各一次，seed2024，40epoch、batch256、最多1024监督位置。原controlLR=.001及两层HSTU保持不变，不使用v5_1后续的Sports半学习率或一层HSTU。这是两个方法在三个已有数据集上的必要对照，不是超参网格，不扩CDs。

训练窗口、数据划分、内容特征、AE更新和优化器设置与原control一致。固定seed20261028抽4096验证用户、每5轮以部署NDCG@10选checkpoint，再完整validation审计。test在ID映射前排除，不能据完整validation回选epoch或调参。按各数据集分别判断，不设跨数据集平均晋级。

## 必要诊断与成本

对每个已选control checkpoint补充直接读取其历史输出头的分数（不训练新模型、不另选epoch），区分“生成网络对自己训练出的源表示是否有作用”与“生成系统整体是否优于独立训练的直接CE”。该头没有直接CE监督，不能用它取代真正的direct CE对照。

记录实际参数、训练时间、峰值显存，以及同设备/相同32用户批量/固定验证子集下的推理耗时。推理计时固定warmup与重复次数，仅作共享设备上的描述，主要结构成本是每用户32个生成网络查询降为0（批量实现可合并前向）。单种子不报告稳定性结论，也不自动开多种子。判断结果写清FM在哪个数据集有正收益，或者尚无支持其开销的证据。

旧版保护hash、源码快照、展开配置、共享初态、数据/selection指纹、checkpoint、逐轮日志、逐用户预测与精确重载核验必须完整。已有run id拒绝覆盖，短程smoke不计正式结果。本轮判断后不直接改v5默认方案。
