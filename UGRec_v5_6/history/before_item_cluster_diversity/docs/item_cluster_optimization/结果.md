本轮以已经获得正向趋势的外接 VLAD K1/G2、token 范数 sqrt(128) 为固定参考，继续研究表示变换容量、簇数与 HSTU 后的聚合。AE encoder/decoder/catalog、HSTU 主体、损失和学习率保持不变；没有返回上一轮 AE 内分簇的负结果路线。

本轮新增7组正式训练，完成3个K/G邻域、2个HSTU后聚合方案、2个输入尺度邻域。全部没有超过固定正收益参考K1/G2的selection及完整NDCG@10，因此当前保留K1/G2、token范数sqrt(128)、sum聚合。它相对原无VLAD基线完整NDCG仍为+2.33%的单种子趋势；本轮没有获得进一步提升，也没有把该结果称为多embedding成功或稳定最优。实现、配置和负结果均保留，原默认未改。

## K/G：检验容量和多簇数量

K1 下 G1/G2/G4 比较派生特征分组与展开容量，G2 下 K1/K2/K4 比较簇 token 数量。为保持每个簇 128 维且不添加输出映射，实现要求 expansion=G，因此 G 改变也改变参数量；不能把它称为同容量纯分组消融。G 改变时新增 VLAD 初态不同，但共享 AE/HSTU/投影/输出头完全相同。

K1/G1 和 K1/G4 的完整 NDCG 分别为 .06054154/.06055480，与原 baseline 很接近，均未改善正收益参考；其 selection 也分别低于参考 4.2669%/2.4855%。K2/G2 完整 .05881403、selection .05799497，也没有填补 K1 到 K4 的性能差距。根据这些结果停止扩展 G/K 网格，没有自动测试 G8 或所有 K×G 组合。

K1 的簇 softmax 恒为 1，没有跨簇分配；G1 下单组门控的正标量又主要被残差 L2 归一化抵消。因此本轮最佳 K1 结果更适合表述为表示变换收益，不能称为学出了多个语义簇。K2/G2 在固定训练历史上，输入簇平均余弦 .7797、上下文化后 .8302，分配归一化熵 .5491；有方向差异并不等于有排序增量。

## 聚合方案：等权、输入质量与上下文选择

固定 K4/G2、sqrt(128) 输入范数，使用已有 selection 最好的多 token 配置作为共同底座。三组的 tokenizer 与共享 backbone 初态完全相同。改变的是 HSTU 后同 item 的聚合；上一轮 learned 映射改变的是 AE decoder/catalog 前的融合，二者不能混同。

等权参考为 z=sum_k h_k。新方案分别为：

\[
\text{mass:}\quad \pi_k=\frac{m_k}{\sum_j m_j},\qquad z=K\sum_k\pi_k h_k;
\]

\[
\text{context:}\quad \pi_k=\operatorname{softmax}_k(q^T\operatorname{LN}(h_k)),\qquad z=K\sum_k\pi_k h_k.
\]

mass 的假设是输入端 VLAD 激活质量能提供被每簇归一化丢掉的强度信息，而非已证明 mass 就是置信度；它不添加参数，也不 detach 质量。context 直接学习哪些上下文化簇更有用，只有共享 128 维 q，没有簇 ID、MLP、新 loss 或附加门控。q 零初始化，K 倍权重使其初始聚合与 sum 一致；K1 时这两种加权方式都退化为单 token 读出。

两种方案都保持 item 内簇置换不变，权重只取当前 item 及其因果上下文；同 item 原 RoPE 和 item-block mask 不变。学习集合聚合的机制参考 Ilse 等 ICML2018《Attention-based Deep Multiple Instance Learning》（arXiv:1802.04712），这里是简化的共享线性评分，不声称复现原论文的完整 MIL 网络。分组机制参考 NeXtVLAD（arXiv:1811.05014）。

mass/context 的完整 NDCG 为 .05848104/.05857392，均低于同配置 sum 的 .06007548，selection 也下降。不能由单种子称为稳定损害，但本轮没有支持替换 sum。

固定256个训练历史的诊断表明两种聚合都实际改变了输出。mass/context的归一化聚合熵为.96655/.98490，有效簇数为3.687/3.854，权重并非完全相同，但也没有强烈选择少数簇。context的q范数从0变为.33528；其聚合相对同checkpoint等权sum的L2变化约9.71%，mass约11.93%。这是训练样本上的表示敏感性诊断，不是同checkpoint的排序消融。

mass组的HSTU后簇平均余弦为.6830，比sum参考的.7509更分散，排序却下降。不能把更低簇相似度当成互补信息已经有效的证明。context的HSTU后余弦为.7676，也未改善排序。本轮否定的是这两个具体设置的替换依据，不能归结为“attention pooling不工作”或“聚合器没有训练到”。

## 尺度邻域：残差与更新分支的比例

阶段 P 的参数邻域均未改善参考，因此依据已经确认的尺度效应，登记并仅补 K1/G2 输入范数 .5sqrt(128)、2sqrt(128) 两组。它们的全模型初态与原参考逐位相同，参数量和优化设置不变。聚合实验仍固定 sqrt(128)，没有将新尺度与新聚合同步调整。

HSTU 有 x+F(LN(x)) 结构。正尺度缩放主要改变直通残差与内部归一化更新的相对强度，LN 并不让整个块对尺度不变。sqrt(D) 有对齐量级的依据，但不保证是最佳数值。该阶段正是检验这一点，而非无依据地扩宽网格。

半倍/两倍尺度的selection为.06162576/.06156149、完整NDCG为.05998968/.06085070，均低于固定参考.06288856/.06197726。相对正收益参考完整指标分别−3.2069%/−1.8177%。两倍尺度相对原无VLAD基线仍略有正向趋势（约+.47%），但低于当前参考；更高Recall或更低NLL也不替代本轮NDCG目标。因此保留原sqrt(128)，不沿结果再扩展尺度。

## 取舍与适用范围

本轮按登记的有限比较结束，不继续扩K/G、温度、LR或多种子。当前工作候选保留K1/G2、sqrt(128)、sum；mass/context暂不采用，不把已拒绝变更再组合起来。原默认配置不自动替换；独立候选配置与结果可供后续复用。最终方案确定后再对关键基线与候选做多种子确认，当前仅作探索证据。

本轮未测所有聚合自由度，也没有穷尽更高G、任意尺度或学习率。若继续探索，先确认单向量表示变换收益能否重复、以及从单压缩latent生成多簇是否有互补信息，再决定是否投入新的结构；不能仅因“有参数可调”自动扩大实验矩阵。

本轮只比较声明的有限邻域，不称已找出全局最优 K/G/尺度/聚合。负结果不证明所有多 embedding 或 attention pooling 无效。VLAD 的输入仍来自单个压缩 latent 的派生表示，多簇没有新信息源；要证明语义互补，需要直接验证分工与排序增量。参数量、诊断中的方向差异或更低训练 CE 都不能替代主指标。
