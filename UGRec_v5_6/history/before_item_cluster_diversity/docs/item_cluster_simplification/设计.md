# VLAD 结构精简与残差坐标适配

## 问题、机制和假设

固定正收益参考为scaled K1/G2、sum：selection NDCG10=0.06288856076556225，完整validation=0.061977255432943315；无VLAD为0.06181346303725844/0.06056862371944789。此前K1/G1仍含D→D映射、组门控，不是真正删除前置映射。本轮不把新方法的改善归因给未经对照验证的分簇。

现NeXtVLAD公式r_k=Σ_g a_gk s_g (u_g-c_k)，u=fc0(x)。它保留输入内容，不是完全由中心表示。D128/K1/G2的34180个新增参数中fc0有33024个（96.62%）；全模型增加约1.06%，区分模块压缩和总模型压缩。

原NetVLAD先对多个描述子的加权残差求和，再逐簇归一化；无扩维/分组。这里每item仅一个描述子，r_k=a_k(x)(x-c_k)。正标量a_k在L2归一化后抵消，assignment在该归一化支路不提供有效路由。因此轻量实现直接用normalize(x-c_k)，删除不必要的assignment、group gate与fc0；它是单描述子NetVLAD的方向等价简化/中心方向bank，并非完整多描述子NetVLAD复现。原论文：https://arxiv.org/abs/1511.07247 ，NeXtVLAD：https://arxiv.org/abs/1811.05014 。

假设H1：有效收益主要来自有尺度约束的坐标变换，未必需要扩维和分组。假设H2：中心残差直接供序列模块使用并非最佳坐标，逐簇共享W可适配HSTU。用normalize(Wr_k)*sqrt(D)，W为D×D无bias、恒等初始化、不改变共同初始参数或RNG。映射发生在残差后、HSTU前，每簇共用W，无concat/簇特有矩阵/MLP或新loss。此W改变可学习方向，不声称改善已经验证。假设H3：单输入的多中心方向是否真的提供互补信息，需要K1/K4配对，而不能只以K1涨点证明多向量有效。

## 固定协议

Beauty/seed2024、40epoch/4040更新/batch256、两层HSTU/D128、rec LR=.001、AE LR=.0001、CE+.1AE几何。AE与catalog单向量不变。每簇最终范数sqrt(128)；保留item-major展开、相同item共享原reverse RoPE、item内全连接/item间因果/padding屏蔽与展开长度分母。HSTU后同item直接sum，不同时修改聚合与LR。

固定4096 validation用户每5轮selection NDCG10选checkpoint；22363完整validation审计已选checkpoint，不回选epoch、不访问test。只以selection作阶段决策，单种子仅趋势。历史参考严格重载，用新目录保存诊断，不向旧run添加文件。

## 阶段A：最小可归因的单token比较（四组）

- norm_k1：sqrt(D)normalize(x)，0新增参数，识别归一化/尺度本身。
- residual_k1：sqrt(D)normalize(x-c)，D=128参数，检验中心是否有必要。
- residual_k1_linear：sqrt(D)normalize(W(x-c))，D+D²=16512参数，直接检验残差后映射，约原模块一半。
- next_k1_linear：在原K1/G2残差后加同一共享W，50564参数，隔离映射在现正收益表示上的作用。这是机制对照，不当作压缩方案。

A后登记阶段决策，记录selection及预算。B至多运行residual_k4与residual_k4_linear（512/16896新增参数），它们构成无/有映射下的K1→K4必要对照，同时验证共享映射对多中心输出的影响。若A发现工程故障/尺度失配，先修复，不以坏运行推进。K4是先前已测的多簇参考，避免新增K网格。B不引入分配温度、不同LR或额外聚合。总上限6组，完成后审计收尾，不自动扩展。
