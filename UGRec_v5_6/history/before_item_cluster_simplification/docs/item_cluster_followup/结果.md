# 多 embedding 后续探索：尺度、AE 内分簇与聚合

本轮检验三个问题：上一轮下降是否来自 HSTU 输入尺度变化；让 VLAD 真正参与 AE 重建和 catalog 编码是否有用；固定求和是否限制了簇的融合。探索固定 Beauty/seed2024，不扩数据集、不扫种子、不访问 test。

本轮新增 5 组正式实验，连同上一轮 3 组共 8 组对照。结果支持修复输入尺度混杂；尚未支持 K4 多 token 的排序增量。尺度匹配 K1 是本轮最佳候选，完整 NDCG@10 相对基线 +2.33%，但它仍是单 token 表示变换，不能当作多向量成功。AE 内 sum 与 learned 融合均未超过基线。保留模块、配置和结果，不自动替换原默认方案。

## 指标与协议

所有正式组均为 40 epoch、4040 次更新、batch256、两层 HSTU、D128、同一训练数据和共享 backbone 初态。每 5 轮在固定 4096 名 validation 用户上以 NDCG@10 选模，再对选定 checkpoint 做完整 22363 人 validation 审计。完整验证不用于回选 epoch。AE LR=.0001、推荐 LR=.001，损失保持 CE + .1 AE 几何项。

## 阶段 A：尺度干预有效，但不支持多 token 增量

当前外接 VLAD 每簇 L2 归一化后范数为 1，基线输入范数约为 sqrt(128)。HSTU 的残差支路保留输入，因此内部 LN 不能消除这一变化。本轮只把簇 token 乘 sqrt(128)，不改变方向、参数量、初始权重、AE、catalog、LR 或损失。

K1/K4 的完整 NDCG@10 相对各自 unit 组分别改善 5.1104%/3.1551%；selection 也分别改善 2.3765%/1.6759%。因而尺度确实是上一轮的重要混杂因素。K1 的完整 NDCG@10 为 .06197726，相对单向量基线 +2.3257%；K4 为 .06007548，相对基线 −.8142%，仍未超过 K1。

K1 只有一个 token，这一收益更适合解释为尺度匹配后新增表示变换的候选收益，不能归功于多 embedding。固定训练历史上的 scaled K4 输入簇平均余弦 .6763、HSTU 后 .7509，说明它们并非完全相同；存在方向差异仍不足以说明这些差异对排序有用。

## 阶段 B：共享 AE 重建/catalog 并未解决问题

AE 内部先由原 encoder 产生 128 维 latent，再由 VLAD 生成 K4 个未归一化残差。decoder 和 catalog 共用这些残差的 sum。历史分支分别对每个簇使用基线共享 normalizer/input_proj，再展开进入 HSTU，HSTU 后仍按 item 求和。这使重建损失实际经过分簇，避免仅修改类名而计算图仍绕过模块。

对照 `ae_sum_merged` 使用完全相同的 AE、decoder、catalog、全部初始参数及优化设置，只在进入 HSTU 前先合并。这两组是分别重训的对照，不能用同一 checkpoint 推理时临时合并替代。

多 token 的 selection NDCG@10 比提前合并低 4.4203%，完整 validation 反而略高 .3077%。不能由两个方向不一致的测量断言提前合并稳定更好；两组均低于单向量基线，也未支持多 token 的净收益。

在相同 256 个训练物品上，基线 raw AE latent 的平均跨物品标准差为 .07354、重建项 .77411；AE sum 多 token 为 .03542/.81632，提前合并为 .03418/.81225。统一编码引入了额外的编码和聚合变换，并未改善该样本上的重建或几何项。基线也远未达到方差目标 1，不能把新方法标准差低于 1 单独视为其失败证据。这些诊断不是独立留出评估，也没有控制 AE 总参数量。

外接与 AE 内分簇之间同时改变了模块位置、归一化、重建/catalog 路径和优化器归属。外接 VLAD 属于推荐优化器 LR=.001；AE 内 VLAD 属于 AE 优化器 LR=.0001。因此跨这两类方案的比较是统一编码方案的比较，不能称作只增加重建梯度的一项消融。

## 分簇和求和的机制证据

本实现每个 item 的簇残差为：

\[
r_k=\sum_g s_g a_{gk}(u_g-c_k),\qquad \sum_k a_{gk}=1.
\]

直接求和得到：

\[
\sum_k r_k=\sum_g s_g u_g-\sum_k m_k c_k,
\qquad m_k=\sum_g s_g a_{gk}.
\]

所以分配权重从第一项的内容和中抵消，只通过中心加权项影响 raw aggregate。内容和不等于原 latent；这不是把原向量划成可相加还原的独立片段。G2/K4 实际是在同一个压缩向量派生的两组特征上分配，没有引入新的源描述子或恢复压缩时丢失的信息。

独立 FP32 代数检查验证了上述等式，数值误差约 1e−8。固定训练物品上，AE sum 多 token 的归一化分配熵为 .99888；将其分配改成均匀后 raw sum 相对 L2 仅变化 1.1785%，规范化 catalog latent 的平均余弦仍为 .9999205。这表明当前学到的分配对该聚合表示影响较弱，不能据此声称均匀分配在推荐指标上等效。该干预没有重新训练，也没有做排序评估。

固定训练历史上，AE sum 多 token 的输入簇平均余弦 .8517，HSTU 后 .8834，比外接尺度匹配 K4 更相似。这是冗余较高的证据，不是所有簇完全坍缩或没有梯度的证据。重建和 CE 对分配、组门控、中心的梯度均非零。

同一 item 共用原 RoPE，item 内全连接，item 间因果，注意力分母为展开长度 T*K。当各簇输入完全相同时，重复 K 份的注意力和与分母中的 K 可相互抵消；测试已验证与单 token 编码的对应关系。多 token 的价值需要来自有用的簇差异，而不是 token 数量本身。

## 阶段 C：可学习聚合

把 decoder/catalog 共用的固定 sum 改为 `Linear(concat(r_1,...,r_K))`，各权重块 W_k 初始化为 I、bias 为 0。其函数初态对应 sum，浮点归约次序可造成微小舍入差异。历史仍保留 K 个 token，HSTU 后仍 sum。该对照只回答 AE item 融合是否需要可学习参数，不回答 HSTU 输出的 learned pooling 是否更好。

可学习融合的 selection=.06033987，完整 NDCG@10=.05921139；相对 AE sum 多 token 分别 +3.7931%/+0.5188%，相对单向量基线完整指标仍 −2.2408%。因此聚合自由度改善了一部分表现，但并未验证多簇交互价值。其 selection 仍低于原单向量基线及 AE sum 提前合并组，本轮没有再训练 learned-merged；实现支持该配置，不能把它写成已测结果。

学习后融合权重相对 sum 初态距离 3.7931%，各块相对其共同均值的偏差占总权重范数 1.1010%，说明已更新但簇间融合差别仍较小。归一化分配熵 .99917，HSTU 后簇余弦 .87991；把分配改为均匀后规范化 catalog 平均余弦 .9999421。没有证据说线性映射已经学出了明确的簇分工，也不能由这些小变化证明更高学习率一定无效。

## 对调参与后续路线的判断

本轮停止新增训练，不扫 LR/K/温度。可学习融合从第 15 轮的 selection .06034 降到第 40 轮 .05159，同时训练 CE 从约 6.7 继续降至约 5.73；其他 K4 组也在 15–20 轮附近达峰。曲线未显示发散或预算末端仍待收敛，不支持优先加长训练。降低 LR 或改变正则化仍可能有效，这轮没有检验，不能宣称已排除调参收益。

已经被支持的优化是尺度匹配。当前更缺少的是“多簇保留互补内容并改善历史建模”的证据。先保留 scaled K1 作为后续单向量候选；未把它选定为最终部署方法，所以本轮不启动多种子。最终采用时再对它和关键基线做稳定性验证。

sum→mean 不再安排训练：当前聚合后立即进入 condition_proj 的 LN，上一轮 512 人核查得到相同 log probability 和 Top10。换成全局缩放不提供新的聚合表达能力。AE decoder 前的 sum 不经过同样的 LN 抵消，因此不能把这条等价关系移用到 AE 聚合。

研究假设需要更准确地表述为：不同 item 内容成分经历史交互后，能否保留互补的排序信息。本轮从单个压缩 latent 生成 K 个残差，并未获得这条主张的证据。若继续多向量研究，更有信息价值的方向是在压缩前从有来源含义的子描述子构建多成分表示，并先验证它确实保留了互补内容；不应先叠加簇 ID、新损失、残差和注意力门控。此项只是下一步研究建议，本轮未实现或训练。
