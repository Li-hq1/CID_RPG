# 逐 item 多簇表示：首轮探索

核心问题：单一 item 状态必须同时承担不同语义/兴趣方向的历史交互，先压成一个 token 可能限制序列建模。研究假设：从同一 AE 单向量中产生 K 个可学习簇残差，分别在 HSTU 中交互，再求和，有助于排序。它不会增加 AE 输入信息；所得簇是学习到的潜在分解，并非已经证实的语义类别。

本轮继承 v5_6 已验证的直接 CE 底座。AE 仍输出单个128维向量，经原归一化和 input_proj 后输入逐 item NeXtVLAD。沿用本地 NeXtVLAD 的展开/组门控/软分配/簇残差机制，但不做时间累计，不使用跨序列位置 BatchNorm，不做 concat 或最后输出映射。使用 expansion=groups=2，使每簇宽度仍是128，从而完整保留 HSTU 的宽度/头数/深度。若沿用旧输出端 G8/E2 会得到32维而改变 HSTU，故不采用。

定义：对每个 item 的向量 x，u=Wx+b 分成 G 个宽 D 的组 u_g，a_gk=softmax_k(W_a u/T)，s_g=sigmoid(W_g u)，v_k=L2Normalize(sum_g a_gk s_g (u_g-c_k))。保留 VLAD 的每簇 L2 归一化，仅省去 concat 和最终映射。单向量普通 NetVLAD 在簇内归一化后会消掉标量软分配权重；这里的分组机制使不同组的相对分配仍能学习。K1时分配softmax恒为1，不把其分配层零梯度误判为故障。

得到 [B,T,K,D]，以 item-major 展开为 [B,T*K,D]。同一 item 的 K token 共享 reverse_position_ids 的原 item 位置；位置是 item 步长，不是簇步长。掩码允许 key_item <= query_item，包括当前 item 所有簇，避免为无序簇引入人为自回归顺序。padding item 的 K 个位置均0、全mask、每层输出清零。不添加簇位置嵌入。HSTU注意力分母仍遵循原 input_length 规则，此时物理长度为T*K；max_seq_len方式同样为原上限*K，避免复制token导致注意力累加幅度人为扩大。

HSTU每层保持 token 独立状态，仅最后 reshape 回 [B,T,K,D] 并沿K直接相加，得到 [B,T,D]。condition_proj 与 ranking_head 在求和之后使用。训练监督位置与标签保持 item 粒度，catalog/正负物品仍由原AE单向量编码，推理最后有效item也先聚合K个输出再读出。总损失仍为CE+.1 AE几何项。

首轮预设三组 Beauty baseline/K1/K4，各 seed2024，40epoch、4040更新、原两层HSTU/LR=.001/batch256，不改AE学习率或loss。K1用于区分新增表示变换与多token趋势；K4同时改变簇相关参数及求和幅度，不能用单项对比证明增益完全来自语义拆分。输出求和再经原LayerNorm可缓和幅度，但原LN的epsilon仍在，不宣称严格尺度不变。无等FLOPs补偿训练。

各组共享AE/HSTU/投影/输出头初态，新增模块最后初始化。固定独立DataLoader随机生成器，新增模块与更长序列改变后续dropout随机数消费，因此不声称逐步随机数相同。每组每5epoch用固定seed20261028的4096验证用户选checkpoint，选定后完整22363人validation一次审计，不用全量回选epoch，不读test。

验收：基线初态逐位匹配；每item共享RoPE与block mask；簇置换等变；未来和padding无影响；K1与原HSTU等价；重复token时注意力尺度一致；真实缓存完整宽度4更新和checkpoint重载；CE到AE/簇分配/中心/HSTU梯度非零（K1分配除外）。结果记录selection/full NDCG@10及Recall/NLL、训练时间/显存/参数量。用训练历史子集诊断簇余弦相似度、分配/质量分布、聚合前后范数，判断是否高度趋同；不同簇不自动等于有用多模态。

本轮不自动扩数据集、不扫K/温度/种子。仅单种子趋势，不声明稳定收益。若缺少多token收益或簇趋同，先报告事实及机制限制，再决定后续路线。
