# UGRec_v5_1 固定方法与调参范围

本版继承 UGRec_v5 的固定 control：原始 Qwen 内容向量经在线 AE 和逐物品 LayerNorm，送入因果 HSTU；历史条件分别形成锚点与 AdaLN 条件。每个历史锚点加独立标准高斯噪声，经一次 Euler 更新得到推荐查询；训练以多个噪声查询的物品概率边缘似然为主目标，另加原有 AE 局部几何损失。默认训练 8 draws、验证 32 draws，无额外速度回归，无 VLAD 或内容残差码。

目录 ≤20000 精确训练 softmax，否则采用 4096 负例修正 softmax；验证始终全目录。默认 AE latent=128、HSTU width=128/2 layers、Flow width=256/2 residual blocks。默认初始化/损失/梯度与 v5 相同，优化仅改变计算内存组织与运行配置的可靠性。

调参问题是确定兼容四数据集的共用结构，并为每个数据集调整专用优化参数。过渡层、MLP 深度、指定 norm 的候选接口详见 [参数接口](参数接口.md)，具体顺序和假设见 [调参计划](调参计划.md)，指标和选模规则见 [指标遵循](指标遵循.md)。候选未经过完整实验前不认定为改进方案。
