# 冻结 CE 后单独训练 FM：一个后续对照

用户最新判断是 CE 与 MSE 都服务于推荐物品，拆两条尾部可能只产生有限间接作用。第一轮显示联合 FM 低于自身先验，CE 读出也未见收益。因此暂不做双尾部，补一个能回答“FM 运输本身是否值得保留”的对照。

## 假设与干预

如果第一轮主要受联合训练干扰或表征漂移影响，固定一个已可用的 CE 模型，再训练 FM，有机会恢复对先验的正向增量。若仍不能改善先验，则当前证据不足以支持为 FM 增加专用 HSTU 尾部。

载入纯 CE 的验证集选模 checkpoint（epoch15），固定 AE、normalizer、输入投影、两层 HSTU、条件投影与排序头，全部处于 eval 模式。全目录 latent 固定，目标/源点停止梯度；重新初始化速度网络，只训练该网络，裁剪也仅针对该网络。没有 CE 或 AE 几何损失，不改变 CE 表征。源点、桥、连续时间、速度标签及解码与原实现一致。

使用 Beauty/seed2024，额外训练40epoch/4040更新，batch256、最多1024监督位置、训练draws1、AdamW LR1e-3/weight decay0.01、相同warmup/cosine调度。默认推理32源样本×4次Euler。每5epoch在原固定4096名validation用户上以NDCG@10选模，再全22363人validation审计并核验重载。固定CE预测必须与父run逐用户完全一致；所有非速度网络状态的字节哈希在训练前后必须一致。test不访问。

主比较为同一个冻结表示下的 FM、无运输先验、CE 排序头。不能把它与联合训练的差异全部归因于单一梯度开关：它还采用分阶段训练、固定表示和关闭历史dropout，且总训练预算增加了一个FM阶段。它是针对“稳定表示之上FM是否有直接增量”的机制对照，不是同成本系统排名。

## 执行与停止

脚本为 `research/frozen_ce_flow.py`，先做2更新真实缓存工程检查，再执行唯一正式run `beauty_frozen_ce_flow_s2024_20261106`。源码快照、研究脚本、父checkpoint/数据/选择用户指纹、优化状态、日志与预测独立保存。公共训练源码不改，旧run指纹不变。不扫描种子/容量/步数/权重，不访问test。

若FM仍低于其先验，停止当前双尾部路线的扩展并汇总限制；不以“遵循FM形式”代替有效性证据。若有可见正增量，再围绕产生增量的机制决定下一个必要实验。本轮不预先安排第二个后续run。
