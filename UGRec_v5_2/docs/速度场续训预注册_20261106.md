# 速度场续训：预算不足假设

触发证据：本次40epoch重训复现旧结果，速度MSE从2.036降至1.058，固定validation子集最佳epoch仍为40。不能据此断言收敛，也不能直接由MSE推断推荐改善。

唯一干预：从`beauty_frozen_ce_flow_rerun_s2024_20261106/best_flow.pt`（epoch40）恢复速度权重、AdamW状态、训练RNG和DataLoader生成器。仅速度网络额外训练80epoch/8080更新；学习率峰值3e-4、10%warmup及cosine，weight decay/裁剪/训练batch及监督位置沿用父run。父CE、目录、所有非速度参数冻结并处于eval。验证噪声与固定4096名选模用户不变，每5epoch按FM聚合NDCG@10选模，保留父checkpoint作为基线候选；最终全validation核验。另保留末轮checkpoint，不能因保留父checkpoint掩盖续训无改善。

成本为原CE预训练+40epoch速度训练+80epoch额外速度训练。此对照同时增加优化预算并重启低学习率调度，只检验这个具体续训策略，不冒充等预算消融、单一学习率消融或多种子证据。若没有显著趋势，不再自动扩大容量或继续延长。

同checkpoint积分诊断预先固定4/16步、同32个源点；候选池必须比较相同唯一候选数的CE深检索、未运输先验及CE直接类别采样。单真值validation不足以证明多兴趣覆盖。
