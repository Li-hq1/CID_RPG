# 有限、可归因的探索计划

当前已按用户追加授权完成Beauty/seed2024的纯CE、串联CE+CFM和冻结CE后单独训练FM；结果见 [初步实验分析](初步实验分析_20261106.md)。FM未改善自身先验，联合MSE也未表现出正向CE收益，暂不推进双尾部或其他训练矩阵。下面保留初始计划作为历史设计，不表示仍须依次执行；后续必须先形成新的必要假设。探索只用seed2024。

## 固定协议

沿用AmazonReviews2014原始2560维Qwen向量、物品顺序/划分、历史50和滑窗监督。test在ID映射前剔除，倒数第二项仅validation。AE统计量只拟合训练物品，目录保留全目录。

正式起点40epoch、batch256、最多1024监督位置、AE batch512、AE/rec LR=1e-4/1e-3、CE温度0.07、噪声1、训练draws1、推理draws32/Euler4步。Sports若采用v5_1校准LR=5e-4，所有参与对照同步，并显式记录，不能动态继承另一聊天的中间赢家。

每5epoch在固定最多4096名validation用户上按NDCG@10选模，索引/噪声种子20261028，同分保留更早checkpoint。足40epoch，重载核验选模预测后全validation审计。评估batch32、不屏蔽历史物品、padding0不入目录。报告NDCG@5/10、Recall@5/10、解码NLL、实际更新数、参数量、时间/显存与推理NFE。全validation含选模用户，不是独立测试集。最终冻结后另行制定多种子与test计划。

## 依证据推进

1. **串联CE＋CFM起点**：`serial_shared.json`。看同checkpoint的排序头、先验、FM；若排序头欠拟合先解决CE/AE学习问题，若FM不能改善先验先查回归和积分，不先扩容量。
2. **专用尾部作用**：起点可用后比较 `serial_shared` 与 `parallel_shared`。每条路径同为2层，但并联总参数更多，因此只能解释为专用尾部整体作用，不能排除容量解释。必要时再补一个有依据的容量对照。
3. **主干梯度隔离作用**：`parallel_shared` 对比默认 `final`（parallel/tail），结构/参数量/目标权重相同，仅改变MSE是否进入共享主干。这是最直接检验“分支拆分”和“梯度隔离”区别的对照。
4. **是否仅需小FM网络**：若专用尾部缺乏证据，再用 `serial_flow_only` 检验CE表征作为固定条件是否足够。这不是默认必跑项目。

次序表示逻辑依赖，不表示立即跑完。固定reference，不随中间赢家漂移。单种子只谈趋势；先证明FM相对其先验存在增量，再考虑权重或容量调参。

## 成本和可归因性

保留 `control.json` 可生成本版独立旧路线参考，不改v5_1。新方向相对control同时改变目标、训练查询数、结构和积分步数，整套分数变化不能单独归因于双尾部或FM。

默认32×4=128个速度查询/用户，旧control为32×1=32，必须列出成本。若需检验积分，可在训练后同checkpoint做预先声明的一步/四步读出，固定噪声；不能遍历步骤/样本数后挑最高分冒充默认。直线条件桥不保证学出的边际场轨迹一步可解。

## 工程与正式结果

真实缓存检查保留128维AE、每路径两层HSTU及256宽/两块速度网络，仅降低batch、查询/更新数、评估人数/样本数。覆盖Beauty/Sports/Toys精确CE及CDs抽样修正，执行更新、全目录刷新、三种读出和checkpoint重载核验。此类输出标记 `engineering_check=true`，短程指标不用于研究结论。

运行器拒绝覆盖，保存源码快照、配置/数据指纹，但未继承v5_1的campaign决策器，不自动做跨run审计。正式比较前核对源码/协议，修源码后重建对照，保留原始失败。只有实际完成的完整结果能写作正式结论。
