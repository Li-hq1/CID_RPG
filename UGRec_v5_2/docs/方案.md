# v5_2：排序表征与条件速度场分别学习

当前研究进度：用户随后提出两路径可能缺少独立价值，已完成纯CE、串联CE+CFM与冻结CE后FM三组初筛。结果未支持FM增量，暂不扩展下述双尾部；当前以纯CE为研究参照。见 [初步实验分析](初步实验分析_20261106.md)。以下保留原设计假设和实现定义，不代表假设已经获得验证。

## 问题和假设

当前 v5/v5_1 control 对一步 Euler 生成结果做物品概率边缘似然，没有路径速度回归，因此不能仅凭速度网络结构称为标准 CFM。本版假设：历史 CE 建立排序能力并优化 AE，CFM MSE 学习连续运输；独立 HSTU 尾部减少两项任务对同一输出表征的要求冲突。

“输出存在 CE 就一定不是 FM”过于绝对。速度网络同时接受分类与回归时，目标通常不再是纯 CFM；而其他分类式 FM 表述也存在。本版选择可核验的纯速度回归路线，不声称 CE 与 FM 在所有理论框架下不兼容。

## 与 FlowRec 的关系

本次核对 [FlowRec arXiv v2](https://arxiv.org/html/2508.17618v2)，未运行官方源码：式(7) L_Prior 是历史先验 CE；式(8)/(11)是直线桥和速度 MSE；式(12)/(13)在速度输出构造的端点上又做分类对齐；式(14)相加三项。

本版借鉴“受排序监督的行为先验＋CFM”，不使用输出端 L_Align，加入独立条件分支与梯度边界。不复制其 Transformer、随机输入调制、超参或分数，也不把“L_Prior 最有效”当成本项目已经验证的事实。其源0→目标1与本仓库源1→目标0仅是时间约定不同，速度符号及积分方向须同时一致。

## 结构与目标

```
z_i = LN(AE(x_i))
s = HSTU_shared(input_proj(z_history))
h_rank = P_rank(HSTU_rank(s))
h_fm = P_fm(HSTU_fm(stopgrad(s)))
a = sqrt(d) * normalize(W_rank h_rank)
L_CE = -log softmax_i(cos(W_rank h_rank, z_i)/T)[y]
```

P_rank/P_fm各为LN＋Linear且独立。尾部从相同权重初始化但不共享参数。每条路径仍是2层HSTU（共享1＋专用1），总HSTU块数为3，不能称为与串联2块严格等参数量。CE通过历史与目录物品两条路径更新AE。

目录≤20000默认精确CE；大目录使用4096个均匀有放回负例，保留重复样本、排除撞正例项并修正分母。这是抽样近似，不声称log-partition无偏。

```
b = stopgrad(a) + sigma*epsilon, epsilon~N(0,I)
c = stopgrad(z_y)
t~Uniform[0,1]
x_t = (1-t)c + t*b
u_t = b-c
L_CFM = E mean_d[(v_theta(x_t,t,h_fm)-u_t)^2]
L = L_CE + L_CFM + 0.1*L_AE_geometry
```

b、c、x_t和u_t均无梯度。t连续采样，按原速度网络1000步标尺缩放，不取整。sigma=1保留非退化源噪声。每监督位置一个独立噪声和时间点，是CFM期望的MC估计；CE不随噪声重复。MSE按维度取均值，权重1只是起点，不能直接对应范数求和的论文权重。

## 梯度边界

| 参数 | 默认CE | 默认CFM | AE几何约束 |
|---|---|---|---|
| 内容AE | 是，历史与目录 | 否，全部路径阻断 | 是 |
| 输入投影、共享HSTU | 是 | 否 | 否 |
| 排序尾部、P_rank、W_rank | 是 | 否，源点detach | 否 |
| FM尾部、P_fm | 否 | 是 | 否 |
| 速度网络 | 否 | 是 | 否 |

`mse_scope=shared` 为FM另建历史图，以 `ae_grad=False` 编码物品，再允许输入投影和HSTU接受MSE；简单detach已有图会同时切断主干，不能替代这一步。串联时同一条件投影接受CE/MSE；并联时排序尾部仍不接受MSE。`mse_scope=flow` 将整个条件detach，只更新速度网络。

原AdaLN零初始化使首步速度为零，部分内部/条件梯度也为零。测试须在非零Jacobian或后续更新后检查边界，不能误判断图。

停止梯度隔离的是当前反向传播；共享主干仍随CE更新，AE仍改变目标几何，全局梯度裁剪也会耦合两组的步长。本版是对当前表示/源分布拟合CFM的联合训练，不声称整个系统等同于冻结数据分布的FM理论设置，或完全消除了全部任务干扰。

## 推理与研究判断

只由历史构造相同分布的源点和条件，从t=1以步长-1/K做K步Euler：`x_next=x-v(x,t,h_fm)/K`。默认K=4，32个独立源点，分别计算全目录cosine-softmax后平均概率。分块仅作用于样本轴，完整softmax分母不变。解码NLL不是连续ODE模型的精确数据似然。

同checkpoint诊断排序头（无噪声/运输）与未运输先验（同噪声、无运输），它们不参与融合或独立选模。FM恢复的工程证据是桥/速度标签正确、速度网络只接MSE、梯度边界正确、推理求解同一场且不使用目标信息。分布与推荐收益仍须正式验证：FM对先验/排序头的增量、样本分散程度、积分步数敏感性和NDCG。MSE下降不等于多模态生成或推荐提升。
