# UGRec_v1 方案：连续条件生成与兴趣分布采样

> 本文于 2026-10-28 依据现有研究与实现整理，以设计顺序描述本阶段方案，不追认历史编写时间。

## 研究问题与假设

RQVAE 路线先把物品语义压缩为离散 ID，再做自回归生成。本阶段假设：文本 embedding 已包含物品内容语义，可以直接在压缩后的连续空间学习条件物品分布；在同一用户条件下多次采样，有机会覆盖不同兴趣模式，改善单次生成最近邻的覆盖。

这里的“多级兴趣”对应对条件分布的多次探索。现有实现没有显式的兴趣层级标签、树状潜变量或多层兴趣路由，不能仅凭多次采样宣称学到了可解释的层级结构。

## 输入与表示

AmazonReviews2014 使用 leave-one-out 序列划分，文本特征准备参考 RPG 数据方案。默认由本地 Qwen3-Embedding-4B 编码物品元数据，得到归一化的 2560 维 float32 embedding；保留 sentence-T5 的历史设置与缓存。

PCA 仅在推荐训练物品上拟合，默认压缩到 128 维并 whiten；之后按推荐训练物品逐维标准化。验证/测试物品使用训练阶段拟合的变换。物品 ID 从 1 开始，0 为 padding。

实现位置：`data/amazon_reviews.py`、`data/embeddings.py`、`data/tigerdiff_data.py`。原始 embedding 缓存共用，PCA 在本版数据路径中计算。

## 条件生成模型

对历史序列的连续物品特征进行输入投影，由因果 Transformer 或 HSTU 输出每个有效位置的状态，投影成 RF 条件 `c`。两种编码器共享后续损失与生成接口。Transformer 使用绝对位置 embedding；HSTU 使用 RoPE 和 SiLU attention。

记目标物品压缩表示为 `z`，噪声 `ε ~ N(0,I)`。代码使用“数据到噪声”的时间方向：

```text
x_t = (1-t) z + t ε
v_target = ε - z
L_RF = E[ ||vθ(x_t,t,c) - (ε-z)||² ]
```

训练时间步离散抽样后归一化。生成从 `t=1` 的高斯噪声出发，反向积分到 `t=0`，恢复条件连续表示；默认 Euler 20 步，也保留 midpoint/rk4。训练使用条件 dropout，生成支持 classifier-free guidance。

默认对所有有效位置监督，因果掩码阻止未来物品进入条件；后续滑动窗口仅监督最后目标，避免重复计算目标。保留 `last_item` 消融。验证/生成使用最后有效历史状态。

实现位置：`models/tigerdiff.py`、`models/hstu.py`、`models/diffusion/diffloss.py`、`models/diffusion/rectified_flow.py`。

## 多次采样与候选排序

固定用户条件，使用 `M` 个独立噪声得到 `M` 个连续样本；每个样本先检索 `C` 个物品，合并去重。如果唯一候选少于 top-k，逐步扩大检索深度补齐。

默认 `M=32`、`C=1`、平方 L2 距离、support 排序。一个候选的支持度等价于汇总其进入各采样候选集时的 `exp(-distance/τ)`，以 logsumexp 实现；同分依次按最小距离和物品 ID 决定。保留 first_seen 和 min_distance 对照。

`eval_sampling_mode=knn` 是单次连续生成后最近邻检索；`diffusion_multi` 使用多次独立生成与聚合。算法位于 `models/evaluation_sampling.py`。

## 训练与验证约定

默认 HSTU 4 层、hidden 512、4 heads，RF MLP width 512、depth 3；推荐学习率 `5e-4`，batch 256，100 epochs，前 10% 优化步 warmup 后 cosine decay。当前主配置每 5 epochs 验证，以 `ndcg@10` 选 best；评估同时记录 recall/ndcg@5/10。

这些是整理后的研究起点，不表示每个历史 checkpoint 都采用这组参数。旧参数见 `docs/run_configs/` 和 checkpoint。保存 latest 用于恢复，保存 best 用于最终测试；日志、TensorBoard、结果都位于本版 `outputs/`。

## 实验矩阵与阶段结论

| 研究变量 | 对照 |
| --- | --- |
| 序列编码器 | Transformer / HSTU |
| 监督位置 | all_positions / last_item |
| 连续生成采样 | 单次最近邻 / 多次采样聚合 |
| 采样预算与排序 | M、C、距离、support/first_seen/min_distance |

研究者已有观察：多次采样较单次最近邻获得提升，Transformer 与 HSTU 效果接近。此次整理没有重新训练或测定提升幅度，不能将不同旧评估协议的结果直接横比。

本阶段把压缩空间固定为 PCA，下一阶段只替换压缩模块，保留条件生成和采样骨架，以区分表示几何与生成模型的影响。
