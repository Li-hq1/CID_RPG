# UGRec v5 方案

本版是从 `UGRec_v4_2` 抽出的原版方案，供后续实验使用。v4、v4_1、v4_2 里的搜索、消融和历史结果都留在原目录，不进入这里。

原版指冻结配置 `configs/frozen.json`：内容特征经过可训练自编码器，历史由 HSTU 编码，查询由一步整流流生成，再用抽样排序学习这个查询。`configs/minimal.json` 只写下和代码默认值不同的字段；按当前默认值展开后，它和冻结配置逐字段相同。

## 要解决的问题

v4_1 同时使用历史分类、带噪恢复分类和生成结果分类，而且训练时要编码整个商品目录。本方案只保留三件事：整流流的速度回归、对实际生成查询的一个排序损失，以及自编码器自己的局部重建目标。

## 一次推荐怎么算出来

物品内容是固定的文本向量。自编码器把它压到 128 维，再做逐物品 LayerNorm，得到物品表示 \(z\)。用户历史经过同一个自编码器后，由 2 层 HSTU 编成条件 \(h\)。

查询不是直接分类，而是一个 128 维向量。它分三步得到：

1. 锚点网络把 \(h\) 变成一个起点方向，再乘上 \(\sqrt{128}\)，记为 \(b\)。
2. 加上缩放后的高斯噪声，真正的起点是 \(b + 0.3\epsilon\)。
3. 速度网络看着这个起点、终点时刻和 \(h\)，预测速度。查询等于起点减去这个速度。噪声为 0 时，就是 \(b - v(b, 1, h)\)。

配置里的 `num_sampling_steps=2` 表示时间网格的两个端点，实际只做一次 Euler 更新。`flow_ranking.steps=4` 只留给其他路径，原版的 endpoint 路径不用它。

评估时，这个查询到当前自编码器编码的全商品目录里做 L2 近邻。同一次请求抽 32 个查询，按 support 汇总成 Top-K。

## 训练目标

总损失是三项：

\[
L = L_{RF} + L_{rank} + 0.1\,L_{AE}
\]

- **速度回归。** 在真实下一件商品的表示和起点之间随机取一个时刻，让速度网络预测从起点指向该商品的速度。构造这条回归时，起点和商品表示停止梯度，避免模型靠挪动端点来减小回归误差。历史条件保持可微。
- **排序。** 只监督走完这一步之后的查询。每步最多 1024 个历史位置，并均匀有放回抽取 1024 个负样本。损失是带全目录修正的抽样 softmax，温度 0.07。分母是全目录配分函数的无偏估计；取对数之后，这项损失本身不是全目录交叉熵的无偏估计。
- **局部自编码器损失。** 每步从训练物品里抽 512 个，计算重建、余弦、方差和相关正则。

排序梯度进入自编码器、历史编码器和生成这条链路。旧的历史分类、带噪恢复分类、teacher 对齐和 AE-only InfoNCE 都关闭。

## 数据与选模

Amazon Reviews 2014，默认 Beauty，留一法。每条序列的最后一件商品是 test，训练和选模都不读它。验证目标是倒数第二件。

训练窗口和当初复现冻结结果时相同：每条序列的第一个窗口监督所有下一件商品，之后的窗口只监督最后一个位置。

每 5 轮在固定的 4096 个验证用户上按 NDCG@10 选 checkpoint。这 4096 人由种子 20261028 一次抽定，不随训练种子改变。训练跑满 40 个 epoch，中途不早停。结束后用选中的 checkpoint 在全部验证用户上再评一次；这个完整验证包含那 4096 人，不是独立测试。

选模和最终评估都由 `scripts/train.sh` 完成。旧的全验证选模入口没有带进本版。

## 已知结果放在哪里

本次只抽出方案，没有重新训练。Beauty 上三种子完整验证的生成结果约 0.058，记录在 `UGRec_v4_2/docs/v4_2_研究报告.md`。seed 2024 的单次复跑是 0.05902158，记录在同一版的冻结实验和 `experiments/rf_ablation_20261029/`。这些数字都不是本版新跑出来的。

`configs/direct_reference.json` 是同一冻结设置下的非生成对照：查询直接由锚点网络输出，不走速度网络。它不是默认方案。2026-10-29 的整流流消融说明，直接预测可以接近原版，但那组实验也不在本版里。

`configs/matched.json` 把冻结设置收成一次前向。训练查询就是推理时的那一步：历史锚点加噪声，速度网络只在这个起点上求值一次，查询等于起点减去速度。损失只保留这个查询的抽样排序和局部自编码器损失，不再另做随机时刻的速度回归。梯度从同一次排序损失进入自编码器、历史编码器和这一步运输。`configs/frozen.json` 仍是原来的两次前向，用来复现 v4_2。

Beauty、40 epoch、固定 4096 人选模后的完整验证 NDCG@10：一次前向三种子 0.057883、0.057670、0.056708，均值 0.05742，样本标准差 0.00063。冻结两次前向的三种子均值是 0.05813±0.00096，单次最低是 0.05712。一次前向落在这个范围内。结果在 `outputs/Beauty/ugrec_v5_matched_s2024`、`ugrec_v5_matched_s2025`、`ugrec_v5_matched_s2026`。

## 代码默认值不是本方案

`joint_training/config.py` 里的 dataclass 默认值是复制代码时带过来的兼容默认，包括更大的网络、关闭的 flow ranking、100 epoch，以及训练后评估 test。不带 `configs/frozen.json` 启动，跑的就不是本方案。正式入口是 `scripts/train.sh`，它读取冻结配置。
