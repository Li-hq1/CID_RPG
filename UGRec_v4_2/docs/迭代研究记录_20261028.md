# v4.1 迭代研究记录

## 约束与研究问题

保留内容压缩—序列建模—连续生成主框架。目标是确定推荐感知表示、可靠梯度路由和条件生成分别带来什么；不以辅助 CE 成绩冒充 flow 成绩，不以直接混合基线充当生成式贡献。

所有新增实验只使用原训练交互，固定 4096 验证用户选 checkpoint，再审计完整 validation；最后一项 test 目标不参与训练、预测、指标或选择。全目录、不屏蔽历史。每个头独立选模。bootstrap 不包含选模不确定性。

## 第一轮：用实际联合模型拆解监督

配置在 `research/configs/round1/`，8组均 seed2024、Beauty、40epochs。原始内容 AE 为 2560→512→256→128；Transformer 128维/2层，RF 256宽/2层；全位置监督；推荐 lr1e-3、AE lr1e-4，局部 AE loss 权重.1；不使用 CFG。对照除声明因素外相同。

| 实验 | 目的 |
|---|---|
| RF only | 变化 AE 空间中的生成基线 |
| CE only | 相同内容 AE 和历史模型的排序参考 |
| CE + RF | 共享表示/历史网络能否改善生成 |
| +生成端 CE .2 / 1 | 高噪声 clean 预测的候选区分 |
| +文本 teacher .1 | 固定语义对齐 |
| +行为 teacher .1 | 训练图协同表征对齐 |
| AE lr3e-4 | 表示适应速度与目标漂移 |

生成端 CE 使用 t≥.5；它与历史独立 CE 分开报告。RF 和生成端 CE 不更新 AE；teacher alignment 的历史和带噪 target 输入可更新 AE，teacher 不更新。

早期决策依据：历史 CE 的推荐能力明显先于 flow 形成，CE+RF 的生成头仍弱于辅助排序头。由此增加第二轮条件先验实验；早期数值不是最终结论。

## 第二轮：历史条件先验与残差运输

配置在 `research/configs/round2/`。令 `a(h)=sqrt(d)·normalize(W h)`，训练路径为：

`b(h,ε)=stopgrad(a(h))+σ ε`

`x_t=(1-t) stopgrad(z_y)+t b(h,ε)`，`v*=b(h,ε)-stopgrad(z_y)`。

RF 不通过 a(h) 或 z_y 更新 AE；a(h) 由历史 CE 训练。推理只需历史，从同一条件先验积分。生成端 CE 和 teacher 对齐可选。本轮比较 σ=.1/.3/.6、生成端 CE、文本/行为对齐、AE学习率和HSTU。

每次评估用相同随机状态计算 flow 与不运行 flow 的 prior control，二者从同一组32个初始点出发。先验只依赖历史和噪声，有测试覆盖。辅助 CE 另提供确定性历史预测。

条件先验/残差生成在现有文献中存在相关工作，本版将其作为可检验设计，完成文献对照前不宣称新颖性。如果提升全部来自先验而 flow 没有增益，会明确报告。

第二轮增加原始内容的 GPU 缓存，减少全目录 AE 编码的反复传输；缓存不进入 checkpoint，原始 CPU 数据与哈希保留，测试验证编码一致。两轮均使用 float32 matmul precision=high；验证固定噪声并恢复训练 RNG。

## 第三轮：噪声端点监督与一步生成

第二轮的关键负结果：许多模型的随机先验排序已经接近辅助 CE，但完整积分显著损害排序。故第三轮增加独立端点损失：输入严格为历史与纯噪声/历史先验，不带目标；`z_hat=b-v(b,t=1,h)` 后做 catalog CE。AE 在该损失中仍断图，AE 由历史 CE 与本地目标更新。

比较端点权重1/5、标准噪声/历史先验、RF权重1/.1/0、文本teacher与AE学习率。每组分别保存 full-ODE、one-step、ranking 的 best checkpoint。一些早期结果中一步明显优于多步，因此不能用一步成绩替代多步成绩；两者始终分开。

## 第四轮：直接监督生成轨迹的最终输出

对从历史+噪声出发的4次Euler更新展开反向传播，得到 `z_gen=Euler4(vθ,b(h,ε),h)`，用 `CE(z_gen, stopgrad(catalog))` 监督实际生成结果。继续保留标准RF局部回归、历史CE和AE正则。与只监督带噪目标恢复、只监督端点一步的区别是：该 loss 的输入和前向轨迹与推理一致。

训练展开使用相同时间离散、取整和Euler运算；测试验证与现有推理 solver 在相同初始状态下逐值一致，且生成轨迹可反传到 denoiser。主配置强制训练/推理步数匹配（4次更新=5个时间点），禁用CFG以保持一致。

比较标准/历史先验、rollout权重1/5、RF权重1/.1/0、文本teacher；另有相同4次积分但无rollout监督的控制。这里的生成损失同样不更新AE；如果后续允许该loss更新AE，必须作为独立、有坍缩监控的实验。

需要注意，sample-wise CE 并非严格的生成分布似然目标，可能鼓励输出集中。RF是否保留多样性、是否带来准确率/新关系迁移收益，要靠无RF控制和生成样本统计检验，不能只看平均排名。

从后续筛查开始，默认只记录固定4096验证用户，入围后用 `research.audit_iteration` 做完整验证，避免每个弱候选重复全目录多样本审计。结果表分别展示筛查子集和完整审计，未审计处为空值；不将子集分数冒充完整验证。

## 第七轮：边缘概率轨迹监督

前述三种子完整 Beauty 审计显示：候选 flow 均值 .058143，匹配 CE-only .058360。标准噪声的一个轨迹 CE 模型在1024验证用户的32 draws中，平均仅产生1.56个不同最近物品；单样本/均值/零噪声解码未见明显劣势。这提示 sample-wise CE 可能过度要求每个噪声分支解释同一目标。

令 p_k(y|h) 为第k个噪声样本经实际4步生成后，在当前目录上的 softmax 概率。比较：

`L_sample = mean_k[−log p_k(y|h)]`

`L_marginal = −log mean_k[p_k(y|h)]`

二者在K=1时相同，Jensen给出 L_marginal≤L_sample。边缘目标让不同分支分担目标解释责任，但**不保证**学出多模态，也不等于目录top1投票评估的精确似然。不同目标的训练loss不可直接比较。

配置在 research/configs/round7/：K=4边缘CE、K=4逐样本CE、K=4边缘CE且无RF MSE，均为Beauty seed2024、40epochs，其他参数保持冻结候选。用相同32 draws评估，并补生成样本诊断。该轮为事后机制探索，不并入前述冻结配置的跨数据确认性比较，也不凭单种子结果宣称新颖性。

最终完整validation：逐样本K4 .059798；边缘K4＋RF .057615；边缘K4无RF .059847。1024用户诊断中的不同最近物品均值依次为2.12、3.29、3.61。子集上最好的边缘＋RF在完整验证反而下降，故不替换冻结候选，也不新增一轮围绕该赢家的盲目搜索。
