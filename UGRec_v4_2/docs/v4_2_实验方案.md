# v4_2：统一排序监督与可扩展联合训练

保留内容 AE → 历史编码 → RF → 检索。所有新生成实验保留 RF velocity MSE、禁止 teacher，只新增一个生成结果排序目标；direct 是明确标注的非生成对照。旧 v4_1 结果与代码保留。

新目标：RF MSE + λ · sampled ranking(generated, AE(candidate)) + 0.1 · AE local objective。候选为批内目标去重 + 256 次均匀物品抽样；query 上限1024，候选数不随目录大小线性增长。不称为全目录 softmax 的无偏估计。端到端更新历史 AE、候选 AE、编码器和生成器；RF 构造的回归样本与速度标签停止梯度。

第一轮：Beauty seed2024、20 epochs 筛查9个配置，比较条件/高斯源、1/4步、subset contrastive/成对hard-negative/flow距离排序、随机时间恢复排序，以及同候选直接排序。固定4096验证用户选模；入围后40epochs及完整验证，不访问test。输入、序列切分、维度与v4_1紧凑实验相同。

预先规定：按第一轮Beauty验证子集选择代表性的高斯源和历史源方案，再固定40epoch配置，比较直接排序、旧无teacher方案；三种子与Sports迁移不根据Sports回调。每组记录每步候选数、训练耗时、显存；同卡基准另做受控计时。ANN只改变检索实现，必须报告相对精确检索的候选召回与指标误差。

研究边界：采样排序与条件先验已有相关工作，组合不自动构成创新；保持RF损失不意味着RF独立贡献已证明。随机时间恢复成绩不能冒充无目标生成成绩。所有新结果为validation。
