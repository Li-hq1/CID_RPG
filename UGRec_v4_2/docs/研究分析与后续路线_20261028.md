# 连续生成式推荐：瓶颈分析与后续研究路线

日期：2026-10-28。分析对象为 v1–v3 历史方案与从 v3 复制的 v4；新增代码和结果仅写入 v4。本文结合当前实现、已有 checkpoint、三篇原论文与新做的探索实验。

## 1. 判断与证据边界

**方案值得继续，但目前最值得研究的问题是“内容表征如何兼容行为记忆与新关系迁移”，其次才是“流匹配如何在该表征上产生额外收益”。当前证据不支持把瓶颈主要归因于没有放开 RF 对 AE 的梯度，也不支持仅凭一次搜索失败判定方法无效。**

当前方案形成了完整的工程训练框架，但“工程上可联合训练”“联合目标有推荐收益”“连续生成比直接排序更有价值”是三个不同命题。前一个已成立，后两个仍需要严格对照。

证据分四类，不应混用：

1. **历史 test**：来自本地已有结果文件；未重新训练或重新测试，配置和初始化不完全匹配。
2. **新验证实验**：全部不使用最后一项 test 目标。22 次紧凑训练中，关键组做 3 seeds，其余单次筛查。
3. **现有 checkpoint 诊断**：固定 4096 个验证用户，比较相同样本的不同解码以及对齐机制。
4. **论文结果**：用于理解设计与构建复现计划，不能与我们的数字直接组成公平排行榜。

紧凑模型用固定 4096 验证用户选择 checkpoint，再报告完整验证集；后者包含选模子集，属于审计，不是独立测试。bootstrap 区间以已训练模型为条件，未包含选模不确定性。这些实验足够定位下一步方向，不能声称取得正式 test 提升或超过论文。

## 2. 当前模型到底学到了什么

### 2.1 表征、监督与梯度

基础流程是：冻结的 2560 维内容特征 → MLP AE（2560→1024→512→128）→ 逐物品 LayerNorm → HSTU/Transformer 历史编码 → 单个条件向量 → RF MLP → 连续样本 → 候选库检索聚合。

当前默认 AE 优化重建、cosine、variance、decorrelation；`relation_mode=none`。因此，默认 AE 没有显式保留训练共现/转移图。它首先在压缩内容空间，而“内容重建好”不保证“能够区分下一件要买什么”。内容相近、可替代、互补、经常先后购买，是不同关系。

启用 AE-only InfoNCE 后：

| 损失/分支 | 更新 AE | 更新序列/RF 网络 |
|---|---|---|
| AE 本地损失 | 是 | 否 |
| RF velocity MSE | 否；历史和 target 的 AE 均断图 | 是 |
| InfoNCE 的历史条件路径 | 是；穿过参数被冻结的推荐网络 | 否 |
| InfoNCE 的正负物品 keys | 是 | 否 |
| InfoNCE 的 noised-target 输入路径 | 否；target 编码仍断图 | 否 |

所以当前已经有真实的推荐反馈进入 AE，不是完全独立训练；但推荐网络只收到 RF 回归信号，没有收到区分候选物品的排序梯度。可移动的当前 AE 同时充当了 keys，缺少 REPA-E 式固定外部语义目标。

逐物品无 affine LayerNorm 使候选范数近似固定为 √128≈11.314，并消除了每个向量的维度均值/尺度。它与 REPA-E 的跨样本 BatchNorm 不是同一种归一化，也不能仅凭“尺度稳定”认为二者等价。本次没有证明 LayerNorm 是主要问题，后续应作匹配消融。

### 2.2 REPA-E 给出的真正启发

[REPA-E 原论文 §3.2、§4.4](https://openaccess.thecvf.com/content/ICCV2025/papers/Leng_REPA-E_Unlocking_VAE_for_End-to-End_Tuning_of_Latent_Diffusion_Transformers_ICCV_2025_paper.pdf) 明确：

- diffusion loss 对 VAE **stop-gradient**，避免 latent 空间退化；
- 对齐 denoiser 中间表征与**固定的预训练感知 teacher**，alignment 同时更新 denoiser、投影层与 VAE；
- 保留 VAE 正则和重建目标；使用 BatchNorm 跟踪变化的 latent 统计。

因此，“完全放开生成损失更新 AE”并不是 REPA-E 的核心。关键是**哪些梯度通过哪条路径、对齐谁、哪些目标保持稳定**。使用一次还是两次 optimizer.step 也不是判断端到端的本质。

你当前更值得修正的是：让推荐网络也从可靠的推荐监督受益，给内容表征稳定的行为/语义参照，并区分 alignment 的 target 输入路径与 RF 的 stop-gradient 路径。历史归档里已有 `contrastive_both_w0.01`（记录的 test NDCG@10≈.02967），所以不能把简单切换成双向更新当作尚未尝试的必胜办法；旧实现也不能替代当前匹配消融。

### 2.3 对比损失存在容易优化的区域

当前直线路径记为 `x_t=(1-t)z_y+tε`，`v*=ε-z_y`，clean 估计为 `z_hat=x_t-t·v_hat`。在低噪声处，`x_t` 已含大量目标信息，InfoNCE 可以变好而不明显增加历史预测能力。

这属于正常的带目标去噪训练，**不是测试泄漏，也不说明生成方法不成立**；问题在于不能把该 loss 下降直接当作推荐能力提高的证据。

固定 256 验证 queries、64 negatives 的诊断：

| 噪声比例 t | 正确历史 InfoNCE | 打乱历史 InfoNCE |
|---|---:|---:|
| 0 | .00225 | .00225 |
| .1 | .00283 | .00288 |
| .5 | .0910 | .1285 |
| .75 | 2.0879 | 3.3865 |
| 1 | 3.2158 | 4.4887 |

t=0 时不经过网络的基线也得到相同 loss。高噪声时正确历史明显有用，因此模型并非完全忽略条件。后续应同时监控：历史独立 CE、高噪声对齐、打乱历史差值、候选 margin；不要只看平均 InfoNCE。

在一个固定 batch 上，InfoNCE 乘 .01 后的 AE encoder 梯度范数约 .0423，本地 AE 项约 .0298。故“小 loss 权重意味着对 AE 几乎无影响”也不成立。若人为打开 RF 的历史 AE 路径，该 batch 梯度约 .978，量级大得多；这只是单 batch 诊断，不是放开梯度后效果的实测结论。

## 3. FMRec 与 MIRAGE 值得借鉴什么

[FMRec，IJCAI 2025](https://www.ijcai.org/proceedings/2025/0346.pdf) 及其 [官方代码](https://github.com/FengLiu-1/FMRec) 使用可学习 item embedding，但设计不止于 ID 查表：预测 clean item、目录级 CE 区分候选、历史交互重建，并让带噪 target 参与序列处理。我们的历史先被压缩为单个向量，RF 不能在不同去噪状态下重新选择历史信息。这是值得测试的条件建模差异，尚未被本次实验单独证实。

[MIRAGE，arXiv:2607.23762](https://arxiv.org/abs/2607.23762) 保留 clean recovery、ranking、history reconstruction，并用**训练交互共现图**的局部 anchors 约束路径；推理不需要在线查图，支持一步预测。因此，其收益不能只解释为“用 ID 学简单对应”，也不能全部归给 manifold。

MIRAGE 表中 Beauty NDCG@10 为 .0494，FMRec 为 .0479，相对约 +3.13%；原始 FMRec 论文自身报告 .049461。论文之间的复现、处理和训练协议有差异：FMRec 表内 Beauty 用户数 22,361，本项目为 22,363。对传统方法或早期生成方法的增幅，不能直接理解成对最强流匹配基线也有同样巨大提升。

对其“几何”解释也应保留可检验性：离散共现图是邻域支持的代理，不等于已知光滑流形。若 anchor `e_j` 在给定 t 时不依赖噪声，则

`E_ε ||(1-t)e_i+tε-e_j||² = ||(1-t)e_i-e_j||² + t² E||ε||²`。

这个简化情形包含邻域吸引及范数相关效应。MIRAGE 的 active-anchor 选择会依赖状态，不能把其完整目标直接化约为上式；但应加入 graph Laplacian、静态邻域拉近、随机/度匹配邻居、范数控制，区分路径机制与普通图平滑的贡献。

另一个需要分开的因素是预测参数化。对于同一 `v_hat`，有

`z_hat-z_y = t(v*-v_hat)`，因此 `||z_hat-z_y||² = t²||v_hat-v*||²`。

预测 x0 与预测 velocity 不只是换输出名称，它改变了时间权重、输入条件和优化性质。本次 x0 实验没有复制 FMRec 的完整网络和损失，不能当成 FMRec 复现或反证。

## 4. “小数据不适合神经网络”需要更精确的表述

两个数据集训练历史中位数均为 4；Beauty 22,363 用户、12,101 物品、153,776 训练交互；Sports 35,598 用户、18,357 物品、225,141 训练交互。它们确实很稀疏，但总规模不是唯一解释。

本次重新构建了仅使用训练交互的传统对照；它们不一定等同于你原来的词频实验，但验证了“简单方法很强”的现象。

| 完整验证集、不屏蔽历史；NDCG@10 | Beauty | Sports |
|---|---:|---:|
| 热门度 | .00785 | .00669 |
| 末物品 Markov 转移计数 | **.05422** | **.03020** |
| 末物品 ItemKNN，K=100 | .03805 | .01828 |
| 历史 ItemKNN，K=100 | .03018 | .01423 |
| 原始内容 embedding 最近邻，末物品 | .02920 | .01583 |
| 原始内容 embedding，历史均值 | .01563 | .00773 |

这说明直接行为转移是强信号；内容语义接近并不足以替代购买关系。但它不能证明神经网络不适合：下节 ID+CE 的神经模型在 Beauty 超过 Markov，在 Sports 与其接近。

“内容方案理论上更适合大数据”也没有无条件保证。真正需要分开的是：目录规模、每物品交互密度、新物品比例、行为关系变化、存储/训练/检索成本。如果数据更大同时行为更密集，ID 方法可能更强；如果目录不断增长且新物品交互稀少，共享内容编码器才有明确迁移机会。

RqVAE/RPG 一类方法的成功也不意味着“重建内容再生成”天然足够。量化与离散前缀会改变监督和检索方式，RPG 还有行为图传播。需要拆解行为信号、表示适配和输出监督，不能把这些收益全部归因于内容特征本身。

## 5. 表示、编码器与目标的紧凑消融

统一 latent/hidden=128、2 层、4 heads，40 epochs；相同训练位置策略、lr=1e-3、batch=256。完整定义与命令见 [research/README](../research/README.md)。相同 epoch 不等于相同 FLOPs/耗时，未分别充分调参。

`adapter` 是 PCA 内容 + 共享残差 MLP，无可训练 item ID；`hybrid` 是内容 + 每物品可训练残差。CE 是仅使用历史的全物品 cosine CE。以下为完整验证集，±为三个种子的样本标准差；单次组明确标注。

| 数据 | 表示/目标/编码器 | NDCG@10 | Recall@10 |
|---|---|---:|---:|
| Beauty | 固定 PCA，CE，Transformer，3 seeds | .034189 ± .001178 | .066315 |
| Beauty | 共享内容 adapter，CE，Transformer，3 seeds | **.051087 ± .000808** | **.097169** |
| Beauty | ID，CE，Transformer，3 seeds | **.057844 ± .000363** | .093130 |
| Beauty | ID，CE，HSTU，3 seeds | .052188 ± .000405 | .082741 |
| Beauty | 内容+ID 残差，CE，Transformer，单次 | .055440 | .103653 |
| Beauty | 固定 PCA，CE，HSTU，单次 | .034075 | .062559 |
| Beauty | 固定 PCA，velocity RF，Transformer，单次 | .018266 | .036086 |
| Beauty | 固定 PCA，x0，Transformer，单次 | .020679 | .038054 |
| Beauty | 固定 PCA，x0+预测端 CE，单次 | .019224 | .035460 |
| Beauty | 内容 adapter，x0+预测端 CE，单次 | .024579 | .046953 |
| Sports | ID，CE，Transformer，3 seeds | .030714 ± .001101 | .049497 |
| Sports | 共享内容 adapter，CE，Transformer，单次 | .028357 | .056042 |

重要解释：

- **固定内容空间限制很明显。** 在同一历史 CE 目标下，增加共享内容适配器已经把 Beauty 从 .03419 提高到 .05109；不需要先增加自由 ID 表。
- **排序监督值得优先建立。** 固定 PCA 下 CE 明显优于当前小预算 RF/x0。不过紧凑 RF 不是主模型 100 epochs 的替代对照，不能把 .01827 和历史 test .03187 横比。
- **简单改成 x0 没有解决问题。** 在带噪预测端加 CE 也没有自动接近历史 CE；需要继续分离时间权重、历史独立监督、target-conditioned attention，而不是把整套 FMRec 的优点压缩成一个输出改动。
- **Transformer 应回到核心对照。** 在当前 ID+CE 配置下，三种子均优于 HSTU；这不是 HSTU 普遍较差的结论，也未证明在主 RF 框架中仍有相同差距。
- Beauty ID+Transformer 对 Markov 的逐用户平均种子 NDCG 差 .003628，bootstrap 95% [.002428,.004781]；Sports 差 .000510，区间 [-.000323,.001342]。后者尚无明确优势证据。
- ID 模型 best 常在 5–15 epochs，之后过拟合；现有联合 AE 模型 best 在 90–95。二者不能共享同一激进早期剪枝规则。

## 6. 更关键的发现：记忆与迁移发生在不同样本上

用**训练集**统计 `(最后一个历史 item, 验证 target)` 是否出现过。Beauty 已见转移只占 11.23%，Sports 占 6.65%。该分层使用 target 仅作事后分析，不能在推理时当作可用 gate。

| NDCG@10，seed2024 | Beauty 已见转移 | Beauty 未见转移 | Sports 已见转移 | Sports 未见转移 |
|---|---:|---:|---:|---:|
| Markov | .47351 | .00116 | .44213 | .00088 |
| ID+CE | .45236 | .00753 | .40365 | .00552 |
| 固定内容 PCA+CE | .18183 | .01671 | — | — |
| 共享内容 adapter+CE | .28044 | **.02172** | .19546 | **.01646** |

Markov 的整体高分主要来自一小部分可直接记忆的转移；共享内容在未出现的转移上更有帮助。这个结果同时出现在两个数据集，比“数据大了可能更好”更接近可验证的研究立足点。

**未见转移不等于冷物品**。当前验证目标在训练中全局从未出现的比例仅 Beauty .228%、Sports .331%；现有 leave-one-out 并不适合支撑强冷启动主张。低频物品也没有统一优势：训练频次≤5 的 Beauty 目标上，adapter .01292、ID .02023、固定 PCA .02319；Sports adapter .00284、ID .00852。行为适配可能损害部分长尾语义结构，需要正则与分层 gate，而不能回避这个负结果。

### 6.1 一个直接的互补性验证

不再训练模型，混合共享内容模型目录概率与训练转移行概率：`p=(1-α)p_content+αp_Markov`。

| 完整验证集，seed2024 内容模型 | Beauty N@10 | Sports N@10 |
|---|---:|---:|
| 内容模型单独 | .05078 | .02836 |
| Markov 基线 | .05422 | .03020 |
| 混合，α=.5 | **.06454** | **.03791** |

α=.5 由 Beauty 的固定 4096 验证用户选择，随后沿用到 Sports；因此 Sports 的这个固定系数结果不依赖重新选择 Sports 最优系数。脚本同时输出 Sports 网格作探索，不能把完整验证集网格最优误称为独立评估。排除对应 4096 选模用户后，Beauty 为 .06420，Sports 为 .03760；这些仍是验证结果。

这是一个非常简单的互补性证据，**本身不是新的生成推荐贡献**。它提示：当前生成器也许在承担本可直接检索的关系记忆，而没有充分发挥内容的跨关系迁移能力。下一步可以研究频次/可靠度门控、共享几何与生成残差，而不是强迫单一 latent 同时完成全部职责。

### 6.2 时间戳与顺序的边界

验证历史末项与 target 时间戳相同的比例为 Beauty 47.68%、Sports 48.54%。同时间戳记录没有可观测严格先后，本项目稳定排序会沿用原文件顺序；时间戳可能只反映日级记录，不能等同于真实同时购买，更不能据此宣称泄漏。

不同时间戳组：Beauty adapter .03055、ID .03015；Sports adapter .02008、ID .01444。与整体指标中的相对关系不同。这提示同日共购/批量评论与跨时间兴趣预测可能混在同一指标里。正式研究应报告时间分层，并测试相同时间戳内随机重排、batch/set 处理的敏感性；当前尚未运行重排实验。

当前按用户 leave-last-two-out 也不是全局时间前向测试。若要讨论真实时间迁移，需要额外建立全局时间切分，确保训练图不包含查询时点之后的其他用户交互。

## 7. 现有联合 checkpoint：收益在哪里、哪里尚不确定

两个已有 checkpoint 用相同 4096 验证用户诊断，加载时严格核对数据特征、item 顺序、训练 mask 与模型状态。

| AE-only InfoNCE checkpoint 解码 | NDCG@10 |
|---|---:|
| 32 draws，support，k=1 | .04302 |
| 相同 samples，k=5 | .04230 |
| 相同 samples，k=10 | .04161 |
| 32 samples 取均值再检索 | .04074 |
| 零初始噪声 | .03974 |
| 仅第一个 sample | .02731 |
| 打乱历史 | .00241 |

模型确实利用历史，多样本也有作用；不能声称已退化成热门度或均值预测。但零噪声与 32-sample 指标接近，值得将确定性/一步预测列为效率基线，而不是先假定复杂采样有不可替代价值。32 draws × 19 次网络求值，另有 CFG 双分支与目录检索，其成本必须一并核算；只报“ODE 20 steps”会低估实际开销。

无 InfoNCE checkpoint 在同用户上为 .04232；InfoNCE 差值 .00070，bootstrap 95% [-.00381,.00515]。当前诊断没有建立稳定收益证据，也不是证明完全没有收益；最终需要同初始化/预算的三种子训练对照。

复用同一批样本，将 support temperature 从 1 调至 64 只由 .04302 到 .04334，配对区间跨零。屏蔽历史物品则到 .04751，差 .00449，区间 [.00336,.00570]。**后者改变了候选协议，不能当成模型改进**；若采用，所有基线、主模型与论文复现必须统一。

生成点离 catalog 的距离也不是充分诊断：InfoNCE checkpoint 最近距离中位数约 5.412，无 InfoNCE 约 3.432，二者排名接近。不能只靠“更贴近候选流形”判断推荐更好。

历史 test 记录供追溯：

| 记录 | test NDCG@10 |
|---|---:|
| v1 PCA RF | .031520 |
| v2 frozen geometry AE | .032236 |
| v3 no InfoNCE | .029568 |
| v3 AE-only InfoNCE | .031866 |

它们没有显示联合训练明确优于两阶段；初始化/协议并非完全匹配，不能据此证明联合一定无效。与上表验证诊断也不是同一个 split。

## 8. Optuna 没超过默认值，能说明什么

不能由此判断模型已经到上限，也不应把一切归因于“还没调模型参数”。当前有更具体的原因：

1. 约 17 个训练超参、约 50 次探索，覆盖很稀疏，且 lr、loss scale、batch、训练长度高度耦合；一次联合搜索没有天然优于人工默认的保证。
2. 历史远端 53-trial 观察来自 Memory，数据库不在本机，未直接审计；记录显示续搜时 pruner warmup 变为 0，22 trials 在 epoch5 被剪。对 best 在90–95的模型尤其不利。
3. 旧 epoch 网格 50–300、步长30实际上不包含默认100；旧范围检查未检查整数网格。
4. 旧搜索以 test 排序完成 trial，验证集仅负责选 checkpoint 和剪枝。这使试验选择依赖 test，历史最好 test 不能再视为独立泛化证据。
5. 主训练入口的随机生成验证会消耗训练 RNG。更改验证频率可能改变训练随机轨迹；本次紧凑实验已保存恢复设备 RNG、固定评估噪声，但生产入口尚未修复，正式 HPO 前应补齐。

本次仅在 v4 修正：

- 新增 `training.evaluate_test`；搜索强制为 false，完成 trial 取 `best_val_score`；普通训练默认仍会最终评估 test。
- study 标记 `objective_split=validation`；拒绝非空旧 test/未知 objective study，避免混用。
- 续搜显式传入配置 sampler/pruner，恢复 warmup 设定；这不等于精确恢复中断前 TPE 内部 RNG 状态。
- epoch step 改为10，包含100，新增整数网格校验；默认使用新的 v4 validation study 名。
- 149 tests 中 1 skipped，其余通过；真实缓存 tiny trial 日志明确跳过 test。没有重新开展大规模搜索。

下一轮应先固定结构和预算，分层搜索：先推荐 lr/weight_decay/dropout，再表示 lr/正则/更新比例，最后对齐权重/温度。隐藏维度、深度、RF宽度、条件交互方式应在结构对照中明确比较。保留默认基线，给慢收敛模型足够 warmup，对入围配置补种子；不再让搜索同时改变太多实验含义。

历史 test 已被反复用于研究选择，即使修改搜索代码，也不会让过去使用的测试集重新变得“未见”。若需要强最终论证，应预留新的数据/时间段或明确说明现有基准上的选择历史。

## 9. 建议的研究路线与停止标准

### P0：先建立能解释现象的最小参考组

先统一候选过滤、训练样本、内容源、split、seed、参数/FLOPs 与评估随机数；补生产入口评估 RNG 隔离。固定最强已知基线：Markov、ItemKNN、ID+Transformer CE、共享内容 adapter+CE、两者简单混合。正式复现 FMRec 后，才逐项比较论文差距。

主要组至少 3 seeds，并报告未见转移/已见转移、频次、时间间隔、真实 cold item、覆盖率和 latency。仅平均 NDCG 不足以说明研究问题。

### P1：优先实现“推荐感知内容空间 + 行为记忆”

在主模型添加**只由历史预测的 ranking head**：

`L = L_RF(stopgrad(AE)) + λ_rank L_CE(history(AE), catalog(AE)) + λ_local L_AE`。

推荐 CE 同时更新历史编码器和 AE；RF 对 AE 继续断图。先验证 AE 不再只围绕带噪 target 的低噪声容易项优化。用 full catalog CE 建立上界；更大目录再换 sampled softmax / in-batch negatives，并控制 false negatives。

比较固定内容、共享 adapter、共享 AE、ID、内容+收缩 ID residual。若使用 `e_i=Norm(fφ(x_i)+g(n_i)r_i)`，gate 只依赖训练频次/可靠度等推理可得信号；新 item 的 residual 为0，避免声称用事后 target 分层做门控。对 adapter 在低频物品上的损失加入语义保持、频次分层正则或冻结分支对照。

这一步最有希望快速改变当前瓶颈，但也可能形成普通判别模型；需要先接受结果，再决定生成模块的角色。

### P2：如果做 REPA-E，应迁移其约束逻辑

保留 RF stop-gradient，增加独立 alignment 分支，将 denoiser 中间层投影对齐至固定 text teacher、仅训练交互产生的 graph/SVD teacher，或二者组合。alignment 同时更新 denoiser、投影层、AE，并允许其带噪 target 输入路径回到 AE；RF 分支仍阻断这些 AE 梯度。不要用一处简单删除 detach 让所有损失意外共享梯度路径。

teacher 先使用固定版本；EMA 作为后续对照，不要把 EMA 自对齐等同于固定外部语义监督。检查 teacher 信号与重建目标是否冲突，监控分时刻梯度、邻域保持与纯历史排序。低噪声对齐、高噪声对齐、历史 ranking 分开消融。

若先离线训练行为 teacher，必须在“一阶段训练”主张中说明额外训练/预处理成本。更准确的表述可以是下游表示与生成联合优化，而不是无条件声称完全省掉所有前置阶段。

### P3：在相同表示上证明 flow 的必要性

控制变量逐项测试，而不是一次改成另一篇完整方法：

| 因素 | 对照 |
|---|---|
| 监督 | 历史 CE / RF / RF+历史 CE |
| 参数化 | velocity / clean item；匹配 time weighting 对照 |
| 条件交互 | 单一历史向量 / noisy target 对历史 cross-attention |
| 更新 | frozen AE / ranking 更新 AE / teacher alignment 更新 AE |
| 几何 | 无图 / Laplacian / target-local anchors / 随机邻居 |
| 推理 | CE / 一步确定性 / 少步 flow / 32-sample flow |
| 编码器 | Transformer / HSTU，分别公平调参 |

先给 flow 更适合推荐的空间与排序信号，再评估其是否改善精度、覆盖、多意图分布或新关系迁移。多样性若是贡献，需在准确率可比条件下比较，不以更低精度换到的覆盖率作充分证据。

### P4：数据扩展应围绕假设

先在现有 Beauty/Sports 补可靠分层和时间敏感性，再增加一个交互更充足的数据集和一个 catalog 持续增长/真实 cold item 场景。这样才能区分“当前方法没优化好”“共享内容有迁移价值”“流匹配适合哪种分布”。单纯增加数据量不自动证明理论优势。

### 明确继续、转向与停止条件

- 若共享表征 + 行为分支在多种子下稳定超过各自单分支，并在新转移或时间外推上有清晰收益：继续以记忆/迁移互补为核心。
- 若 REPA-style alignment 在相同 ranking 监督和预算下进一步改善效果或减少训练成本：它才构成联合训练的实证贡献。
- 若 flow 在同一表征、同一数据、合理优化与公平预算下，仍没有精度/覆盖/效率上的优势：将它降为可选模块或停止强调生成式主张，不必为了保持最初结构而保留。
- 若只有几个已见转移导致整体提升、长尾和时间外推仍恶化：调整研究主张与评估场景，不能用“以后大数据会更好”填补证据。

最值得形成的研究问题是：**如何让连续内容表示保留对未见关系的迁移能力，同时吸收可直接记忆的协同行为；在这个空间里，生成建模是否比直接排序多解决了一个明确问题。** 当前两个数据集上的分层与简单混合给了这一问题初步实证基础，但尚未完成方法创新与正式验证。
