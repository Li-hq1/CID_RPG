# 查询落在模式之间，还是贴错了模式

日期：2026-10-29。对象是 v4_2 冻结的一步生成 checkpoint 和直接排序 checkpoint，Beauty 与 Sports，种子 2024/2025/2026。没有重训，没有读测试标签。脚本 `research/mode_gap.py`，汇总 `outputs/unified_20261028/mode_gap/summary.json`。

## 判定

后继集合只来自训练序列里、验证历史最后一件商品的转移。均值是这些后继在该 checkpoint 自己的 128 维空间里的频率加权平均。验证目标只在事后用来判断这次转移是否见过、最近邻是否命中。

主群体是：目标属于这些后继，且不同后继至少两个。只有在这里，均值才可能落在真实物品之间。一个后继没有“模式之间”；目标不在后继里时，它本身就不是被平均的模式。

两类几何分开看：

- 欧氏空隙：查询到均值的距离，小于它到最近目录物品的距离，且最近邻不是目标。
- 方向平均：把查询、均值和每个后继都归一化之后，查询更接近均值的方向，而不是任何一个后继的方向。

生成模型用的是去掉起点噪声后的一步映射。直接排序用排序头。32 次抽样只用来数不同的最近物品，种子固定为 20261028。和已保存的零噪声或直接排序 top-1 相比，最近邻一致率约 0.998；剩下的差别是距离小于 0.005 的近邻互换。

## 主群体很小

| | 验证用户 | 主群体 | 占比 | 多个后继但目标未见 |
|---|---:|---:|---:|---:|
| Beauty | 22363 | 2499 | 11.2% | 19230 |
| Sports | 35598 | 2355 | 6.6% | 32211 |

Beauty 主群体里，后继数等于 2 的只有 34 人，Sports 只有 12 人。熵的三分位是在主群体内部切的，低段上界已经是 Beauty 2.71 nat、Sports 3.01 nat，对应的有效后继数大约是十几个。所以“高熵”是在一群本来就很分散的已见转移里再分出更分散的三分之一，不是两个模式对三十个模式。

## 欧氏空隙主要是半径不同

物品表示经过逐物品 LayerNorm，范数中位数是 11.31。一步生成的查询范数中位数大约是 19–24，直接排序大约是 9–12。

Beauty 高熵错误里，查询比最近物品更靠近均值的比例：一步生成三种子平均 0.9%，直接排序 94%。Sports 上生成侧接近 0，直接排序是 41%–82%，种子之间差得大。生成侧的最近邻距离中位数仍有 13–17，并没有贴到物品上；它只是因为查询很长，离球面物品比离短的均值更近。直接排序的查询较短，短均值就落在它和所有物品之间。把均值改成均匀平均，这个欧氏划分基本不变。

因此欧氏标签不能当成“生成避开了均值、直接排序掉进空隙”。两边的留出 NDCG 并没有跟着这个标签分开。

## 方向上，两边都指向平均

主群体里，查询方向比任何一个后继都更接近均值方向的比例：

| | Beauty 三种子 | Sports 三种子 |
|---|---|---|
| 一步生成 | 0.78 / 0.77 / 0.66 | 0.76 / 0.79 / 0.77 |
| 直接排序 | 0.77 / 0.78 / 0.75 | 0.79 / 0.81 / 0.83 |

高熵错误上的比例也在 0.65–0.82，没有集中成“只有高熵才指向平均”。后继数等于 2 的那几十人里，这个比例大约是 0.6–0.7，人数太少，不能单独下结论，但方向并没有反过来。

主群体的 top-1 命中率两边都低：Beauty 大约 0.12–0.15，Sports 大约 0.09–0.11。已保存的 32 样本 NDCG@10 在主群体上反而高，因为目标是已见转移，经常出现在前十名里：Beauty 低熵三分位大约 0.40–0.44，高熵大约 0.23–0.24；Sports 低熵大约 0.26–0.28，高熵大约 0.18–0.20。高熵更难，但一步生成和直接排序在这两个三分位上一起升降。

一步生成的 32 次抽样，主群体里不同最近物品的平均数大约是 1.8–2.0，高熵三分位大约是 1.6–1.8。

## 对下一步的含义

预先定下的标准是：空隙类错误要占可观比例，并且集中在高熵历史上，当前这种一步生成才还有精度上的位置。诊断结果不是这样。欧氏空隙主要反映查询半径，不反映排序质量。去掉半径之后，一步生成和直接排序都经常指向后继的平均方向，高熵切片上的 NDCG 也没有分开。多数验证用户的目标根本不在训练后继里，生成查询的最近邻又大多落在这个后继集合之外。

还成立的现象是：在少数确实有多个已见后继的历史上，单个查询的方向偏向它们的平均，而现有的 32 次抽样并没有把这些后继分开。若以后要让抽样覆盖不同后继，评价指标得能看见这种覆盖；只看一个留出目标的 NDCG，这一步没有显示出值得做的精度差。
