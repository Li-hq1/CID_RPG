# v4.1：连续生成框架的迭代实验

日期：2026-10-28。保留内容 AE → 序列编码 → 连续生成 → 内容目录检索。实现与实验位于 v4.1，v1–v4 保留。新增实验均为验证集研究，不是正式测试结果。

**本轮支持继续研究内容联合表示；尚未证明连续生成相对同内容排序模型的独立收益。** 有限计划的51组训练均已完成，每组40epochs，入围模型和关键控制完成完整验证审计。未入围组仅保留筛查子集结果。新增实现最终168项测试，167通过、1跳过；真实缓存主入口的轨迹监督＋teacher smoke成功并跳过test。

## 本轮实际改变的研究问题

此前需要判断联合框架能否运行；现在需要判断三个可分别证伪的命题：

1. 内容 AE 是否因推荐梯度而获得有效的行为适配，而不只是改善重建？
2. 从纯历史和噪声出发的实际生成轨迹，能否达到或超过相同内容模型的直接排序能力？
3. 在推荐轨迹监督之外，RF 概率运输目标本身是否仍带来准确率、关系迁移或多样性收益？

辅助排序头既是表示学习的监督，也是强参考。它的成绩不能作为生成头的成绩。生成头超过较弱的 RF-only 也不足以回答第三个问题。

## 目标与梯度

内容物品表示为 z_i = LN(AE(f_i))；历史编码为 h；目录为所有当前 z_i。历史独立 CE 对整个目录作候选区分，允许梯度进入历史侧和候选侧 AE。它避免用带噪目标的恢复能力代替历史预测能力。

RF 的路径为 x_t=(1−t)sg(z_y)+t·b(h,ε)，速度目标为 b(h,ε)−sg(z_y)。RF 两侧的 AE 都断图。可选条件先验 b=sg(√d·normalize(W h))+σε，或者 b=ε。

先尝试高噪声恢复 CE；再尝试只从 b 和 h 计算的一步端点 CE；最后展开实际4次 Euler 更新，对生成终点做目录 CE。训练轨迹与推理使用相同离散时间和更新运算，并有逐值一致的测试。所有这些生成 CE 的候选目录及 AE 路径均断图。

另外实现固定文本/训练图 teacher 对 denoiser 中间特征的对齐。该独立分支允许梯度进入 AE 与生成器，teacher 固定。这是可消融的 REPA-E 式梯度桥；没有默认打开 RF→AE，也没有把梯度连通等同于有效创新。

总目标为历史 CE + λ_RF·RF MSE + λ_gen·生成轨迹/端点 CE + λ_pred·高噪声恢复 CE + λ_align·固定 teacher 对齐 + λ_AE·AE 本地目标。各项独立开关，原 legacy 路径继续保留。

## 验证边界

所有新增训练、调参和诊断只使用 train/validation，最后一项 test 目标不参与。固定4096验证用户选模，入围后审计完整 validation，并单独报告其余验证用户；完整审计不是独立测试。模型、噪声、检索目录、是否屏蔽历史均明确固定，不用不同候选协议制造改进。

候选在第四轮结束后，仅由预先规定的验证子集 flow 分数选定，然后固定配置迁移至 Sports。两个数据集均补三个种子，并与同维度/训练预算的 CE-only 比较。额外模型规模、编码器、学习率探索只作后续研究线索，不根据 Sports 结果回选候选。

这些结果不能直接与 v3 的512维/100epochs及历史 test 对比，也不构成 FMRec/MIRAGE 的公平复现或 SOTA 声明。原有 test 已有历史选择，正式论文还需要干净的新数据或新的时间切分。

## 科研意义的判别标准

若轨迹监督恢复了生成能力，但 RF 与无 RF 控制相当，能支持“目标与推理不一致是瓶颈”，不能支持“RF 比一般连续预测更优”。若零噪声与多样本相当、样本明显收缩，则应进一步研究生成分布是否有可测量价值；不能靠更复杂的采样流程维护生成式叙事。

若联合内容表示在未见转移上更强，但在已见转移上弱，应围绕行为记忆与语义迁移的分工研究。未见转移不等于冷物品；真正冷启动、长尾或规模收益均需各自的分层与切分实验。

条件先验、端点/轨迹 CE、teacher alignment 单个模块都有相关研究先例。本轮产出首先是可运行且可证伪的研究基线，不能把组件组合本身视为已建立的新颖性。可形成贡献的问题应同时满足：明确机制、必要的匹配控制、多个数据/随机种子验证，以及比纯排序额外解决的实际困难。

## 已确认的结果

### 1. 联合内容表示有价值；生成的额外价值尚未建立

以下是完整 validation，神经模型均为 seeds2024/2025/2026 的均值±样本标准差。候选由 Beauty 固定4096用户的 flow 分数选择后冻结，Sports 未重新调参。所有模型使用完整目录、不屏蔽历史。

| NDCG@10 | Beauty | Sports |
|---|---:|---:|
| 训练转移 Markov | .054216 | .030204 |
| 同内容 AE＋直接 CE | **.058360 ± .000496** | **.033524 ± .000234** |
| 联合模型：4步 flow | .058143 ± .000715 | .033086 ± .000785 |
| 联合模型：辅助 ranking | .058178 ± .000484 | .033661 ± .000178 |
| 先前紧凑 ID＋CE，参考而非参数量匹配消融 | .057844 ± .000363 | .030714 ± .001101 |

flow 相对匹配 CE 的逐用户、种子平均差：Beauty −.000217，bootstrap95% [−.001095,.000650]；Sports −.000437，[−.001078,.000188]。排除选模子集后结论相同。**目前不能声称 flow 超过了相同内容模型的直接排序。**

相对同一 checkpoint、同一组初始噪声且不运行 flow 的 prior control，Beauty +.000531，区间跨零；Sports +.000480，区间 [.000120,.000823]。Sports 的小幅起点修正不等于超过确定性排序，更不等于已证明概率生成的必要性。

以上区间以已训练模型为条件，先对三个种子逐用户平均，再bootstrap用户，不涵盖训练、超参/选模不确定性，也不是独立测试的显著性检验。

### 2. 推荐梯度进入 AE 是本轮最强的机制证据

保留完全相同的本地 AE 和 teacher loss，仅关闭 history CE、catalog CE、teacher 三条进入 AE 的梯度，其他推荐网络仍正常训练：Beauty flow 从 .058763 降到 **.024037**，差 −.034726，配对区间 [−.037200,−.032280]。

这支持在当前40epochs预算下进行推荐感知联合表示学习，而不是让 AE 仅重建内容。它不能证明任意两阶段预训练都较差，也不能代替长预算/预训练初始化的匹配对照。当前证据支持“推荐梯度改善表示”，不支持“RF梯度应该全部放开”。

### 3. 监督实际生成过程，比只监督带噪恢复更有效

Beauty seed2024 的逐步诊断：RF-only .010459；历史 CE＋RF 的 flow .032881；加高噪声预测 CE .033421。历史条件先验也没有自动解决问题，flow 经常损害已不错的起点。

更干净的匹配比较是相同历史先验、RF1、prediction CE.2、4次Euler：无 rollout 监督 .042833；加 rollout CE1 .058254。两者均无 teacher。纯噪声端点 CE 可以改善一步预测，但不能把一步成绩冒充完整积分成绩。

这说明训练—推理目标不一致是实质瓶颈。轨迹监督恢复了生成能力，却仍没有自动超越直接排序。

### 4. RF 和 teacher 尚无独立收益的可靠证据

| Beauty seed2024，完整 validation | Flow NDCG@10 |
|---|---:|
| 冻结候选：RF1、rollout1、文本teacher.1 | .058763 |
| 仅移除 RF MSE | .058944 |
| 仅移除 teacher | .058254 |

无RF相对主候选差 +.000182，配对区间 [−.000986,.001365]；无teacher差 −.000509，区间 [−.001674,.000713]。这是单种子控制，尚不能认定两组件必需，亦不能认定它们在所有配置中均无效。REPA-E式桥已实现，但“梯度能到达”与“额外性能收益”仍是不同结论。

### 5. 不能把编码器或模型大小视为单一答案

| Beauty seed2024，保持生成目标 | Flow NDCG@10 |
|---|---:|
| Transformer128，lr1e-3 | .058763 |
| HSTU128，lr1e-3 | .061123 |
| Transformer128，lr5e-4 | .059514 |
| Transformer/latent256、RF512 | .057180 |

HSTU 的同内容 CE 对照为 .060905；flow差 +.000219，区间 [−.001314,.001684]。因此 HSTU 的单次提分主要不能归因于新增 flow 收益。它也说明先前 ID＋CE 实验里 Transformer 更强，并不意味着应该普遍放弃 HSTU。更大模型在这次单种子预算下没有改善，较低学习率略好；这些仍需各自补种子，不能把它们包装成充分调参后的全局结论。

## 生成分布是否有实际价值

事后诊断使用选模子集前1024用户，未据此换模型或解码器。Beauty冻结候选的32 draws平均只有2.10个不同最近物品；HSTU候选为2.01，Sports为1.74。标准噪声＋较强轨迹CE的一个模型则只有1.56。不同候选的先验本来就不同，不能把这些数字当作校准熵或直接比较全部概率质量。

Beauty冻结候选：32样本 .06873、单样本 .06789、均值 .06992、零噪声 .06954；Sports：32样本 .03504、单样本 .03411、均值 .03394、零噪声 .03362。它们仅是1024用户的诊断，**不是完整验证成绩**，也没有给出稳定的随机采样必要性结论。

本轮因此增加 K=4 边缘概率监督，和相同K的逐样本CE、边缘目标去RF作控制。该轮结果单独作为机制探索报告，不替换已冻结的三种子迁移结论。

### 边缘概率监督的最终结果

| Beauty seed2024，40epochs | 完整验证 Flow N@10 | 1024用户诊断：32 draws的不同最近物品均值 |
|---|---:|---:|
| K=4逐样本CE＋RF1 | .059798 | 2.12 |
| K=4边缘CE＋RF1 | .057615 | 3.29 |
| K=4边缘CE、RF0 | .059847 | 3.61 |

边缘CE＋RF相对相同K的逐样本CE，差 −.002183，配对区间 [−.003726,−.000674]；边缘CE去RF则差 +.000050，区间 [−.001485,.001601]。这些仍是单种子探索，不能宣称普遍优劣。

因此这个改动改变了样本分散程度，却没有建立准确率收益。尤其值得保留的负结果是：K=4边缘模型在4096选模子集 best .062367，高于K=4逐样本的 .059787；完整验证却反过来。它直观说明为何不能把一次筛查/HPO赢家当成方法已改善，也说明后续必须补种子与独立评估。

RF0边缘目标值得作为“能否以相近准确率保留更多样本支持”的后续基线，尚不能把几个最近物品的增加解释为已解决多模态。所有模型的初始噪声支持也不同于标准高斯，分散程度与校准、目录覆盖和用户效用仍需分开研究。

## 一个更强的互补性对照

不重训，只把本轮三种子内容AE＋CE的目录概率，与**训练集**末项转移行概率按.5/.5混合；系数沿用先前v4 Beauty研究已选定的.5，本轮不重新搜索，Sports也不调系数。无转移支持的历史仍保持原CE排序。实现逐用户断言：不混合时的预测与已审计CE预测完全一致。

| 三种子平均，完整validation NDCG@10 | Beauty | Sports |
|---|---:|---:|
| 内容AE＋CE | .058360 | .033524 |
| 固定系数的记忆＋内容诊断 | **.066332** | **.038586** |

这不是新的生成方法或论文贡献，且仍是验证结果。它说明当前框架还有明显的行为记忆与内容迁移互补空间，也给未来复杂的生成机制提供了应认真比较的简单参考。新机制若只改善弱RF、却不能解释与这个参考的关系，论证仍不充分。

## 后续应该围绕什么推进

建议继续这个框架，但把论文问题从“把两个训练阶段合并”收紧为：**怎样在推荐适配的内容空间中，同时保留语义迁移、可靠行为记忆和有用的生成分布？**

1. **保留最小强参考。** 内容AE＋CE、匹配ID方法、Markov、同噪声prior、无RF生成都应长期保留。生成机制必须在这些参考之上证明额外价值。
2. **优先解决已见关系与新关系的分工。** 可研究基于训练支持度的历史条件行为先验/锚点，让连续生成承担内容迁移与残差修正。推理可靠度只能依赖历史和训练统计，不能使用事后target分层。先与简单概率混合比较，再判断复杂运输是否必要。
3. **保护低频语义几何。** 将固定内容几何与可学习行为残差分开，考虑频次调节的适配强度/邻域约束；需用固定PCA、共享adapter、普通图平滑等控制检验。全局teacher平均收益不足以证明长尾结构被保留。
4. **生成问题要用分布指标验证。** 边缘监督之外，检查样本去重、目标覆盖、校准、准确率—多样性权衡和推理成本。若确定性映射始终同样好，就应承认该数据/任务尚未展示随机生成价值，而不是用复杂采样叙事掩盖这一点。
5. **调参应分层进行。** 当前有目标错配和表示权衡的实证，不宜再同时搜索十几个高度耦合参数。先固定可信目标，再分别搜编码器/容量、推荐优化、AE适配与正则，最后搜生成权重。已有Optuna协议问题和修复见v4报告。

这些都是明确可检验的研究方向，但条件先验、可微分采样监督、teacher对齐、混合概率各自都有先例。正式创新点仍需文献对照与完整机制证据，本轮不宣称已获得新颖性或SOTA。
