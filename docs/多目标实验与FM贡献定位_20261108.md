# 多目标实验与 FM 贡献定位

日期：2026-11-08（用户本地日期）。本文件是文献核对与新增实验设计，不是新实验结果。本轮未训练、未评价 test、未修改旧版本算法或配置。

## 用户确定的研究定位

保留原 leave-one-out（LOO）实验，在同一论文中增加未来多目标预测实验，用来检验 FM 是否提供下一物品排序之外的有效未来覆盖。新增实验不替代原任务，也不预先把原结果归因于 benchmark。

拟检验的核心假设：保留下一物品 CE 对近期相关性的约束，让条件 FM 学习同一历史对应的未来物品表示分布；其生成样本能在固定推荐列表大小下覆盖更多真实未来目标。FM 的独立价值必须相对同样使用未来标签的非 FM 方法成立。

论文贡献应由结果决定。若 FM 只优于单目标 CE、未超过同监督的多目标 CE，只能说明未来监督有效；若样本更分散而真实未来覆盖不提升，不能写成有用的多兴趣建模。

## 已有本地证据

- `experiments/multi_future_20261105/DIAGNOSTICS.md`：下一件与较远未来对历史的依赖不同；现有混合查询没有有效分工覆盖不同后继。这是只读诊断，不是多目标模型训练结果。
- `UGRec_v5_2/docs/初步实验分析_20261106.md`：Beauty/seed2024 的当前 CFM 与解码组合未改善 CE 或自身先验；冻结 CE 后依然没有改善，故不能只用共享梯度冲突解释差距。
- `UGRec_v5_2/docs/双流重训与候选预算实验分析_20261106.md`：延长速度训练、增加积分步数后仍无有效增量；固定唯一候选数量时，FM 候选不如更深 CE 检索或未运输先验。这些结果仅是原协议的单种子 validation 趋势。

这些证据支持重新研究监督目标和能力评价，但尚不支持“FM 在多目标任务中更好”或“问题完全在 benchmark”。既有负结果保留。

## 文献核对

1. **ComiRec，KDD 2020**：已有多兴趣召回与准确率/类别多样性研究。其 strong-generalization 协议将用户按 8:1:1 划分，再用验证/测试用户前 80% 历史预测后 20% 行为。该用户划分和原 LOO 不同，不能只截取后 20% 标签就称为复现完整协议。它是多目标评测的直接先例和应考虑的非 FM 基线。
   原文：https://arxiv.org/html/2005.09347

2. **REMI，RecSys 2023**：研究多兴趣训练的负采样和路由塌缩。它说明多兴趣能力并非 FM 独有，实际多兴趣训练也可能失败；可作为后续正式外部基线之一。
   原文：https://arxiv.org/html/2302.14532

3. **FlowCF，KDD 2025**：在用户多物品交互向量上构造 flow，主要是协同过滤而非当前历史条件的未来窗口任务。原文使用 MovieLens-1M、MovieLens-20M、Amazon-Beauty，8:1:1 数据划分和全目录评测。其交互向量预测含 MSE，不应据当前实现的失败否定平方误差或 FM。不能直接搬用其分数作为新协议基线。
   原文：https://arxiv.org/html/2502.07303v2

4. **GMFlowRec，2025 arXiv 版本**：Gaussian-mixture FM 用于多域行为模式；该版本实验明确采用 LOO，每例一个正例加 999 个同域负例。多域、多兴趣、多目标评测不能等同。此处仅核对该 arXiv 版本，不据此概括所有后续版本。
   原文：https://arxiv.org/html/2510.21021

5. **OT-FlowRec，2026-10-12 arXiv v1**：已明确提出多兴趣、多桥 FM，是当前研究动机的近邻。其式(10)监督 ground-truth next item，附录 B 将任务定义为下一时间步物品预测。不能把其“多兴趣”描述当成已经验证未来多正例覆盖；也不能据本次检索声称本研究首次提出该评测。本文当前仅为预印本，不视为成熟统一 benchmark。
   原文：https://arxiv.org/html/2610.16038

6. **Flow Matching for Generative Modeling，ICLR 2023**：FM 回归的是给定桥状态和时间的向量场，MSE 本身不意味着最终生成只能落在一个均值上。是否形成有用多模态由条件信息、监督、拟合和解码共同决定。
   原文：https://arxiv.org/abs/2210.02747

与已有工作的潜在区别应落在“下一物品排序与未来覆盖的任务分工、相同未来监督下的机制增量、固定列表大小下的证据”，而不是笼统的“把 FM 加进推荐”或“FM 可表达多兴趣”。

## 新实验的任务与数据

原 LOO 主表与历史结论保留。新增任务给定预测时点 t 的历史 H，输出一次固定大小 Top-K 列表，评价后续 h 次交互形成的目标集合 Y。窗口内不追加真实测试行为后重新推荐，不转成逐步 teacher-forcing 的 h 次下一物品预测。

探索优先复用一个已有数据集。先统计训练可用前缀、序列长度、能完整留出训练/验证/测试窗口的用户比例、目标去重后数量和目录覆盖。窗口 h 依据任务和这份数据审计事先固定；h=3 可以作为候选，但不是未经审计就锁定的最终设置。不为寻找正收益枚举窗口、数据集和权重。

若原有数据过短导致大比例用户丢失，再选已有多兴趣研究使用的 Amazon Books 或 Taobao，并在正式阶段增加 ComiRec/REMI 基线。优先选择与问题相符、保留足够历史的数据，不把是否有 FM 收益作为换数据集的依据。

必须重新构建独立划分并重训参与比较的模型。将旧 LOO 的最后 h 项直接作为新目标，通常会把旧训练中的 h-2 项纳入评价，旧 checkpoint 会污染新任务。新训练标签与未来监督窗口不得跨入新验证/测试区间；AE、归一化统计和数据拟合也按新训练区间审计。候选目录的可用信息规则应预先声明并在所有模型间一致。

可采用全局时间段和完整未来窗口；若沿用逐用户连续区间划分，应明确其时间泛化限制。新窗口所有方法使用同一用户集、历史、标签、目录、重复物品规则和候选过滤。对短序列筛选造成的人群变化单独报告。

新多目标表与旧 LOO 表采用各自的训练划分、验证选模及 checkpoint。两张表反映同一方法在两个任务下的能力，不自动意味着同一个 checkpoint 同时具有两种优势。若要做后一个主张，必须另加同一模型/预测时点的共同评价，明确样本和历史。

## 学习对象：未来物品分布，而不是未来均值向量

保持 L_next-CE。在一个固定训练前缀下，从其完全处于训练期的未来 h 项中抽取目标 z_j（固定等权作为初始设定），构造条件桥并回归速度：

```text
j ~ Uniform({1,...,h})
x0 ~ history-conditioned source
x1 = stopgrad(item_embedding(y_j))
xt = (1-t)*x0 + t*x1
L_future-CFM = E[ ||v(xt,t,H) - (x1-x0)||^2 ]
L_total = L_next-CE + lambda*L_future-CFM + existing representation objective
```

上式使用 0→1 的说明性时间方向；本地 v5_2 使用相反约定，实现时须同步变换速度符号与积分方向。源点和目标的梯度范围延续经核验的明确规则，不据此新增双尾部或梯度模块。

不要先平均未来物品 embedding 再作为唯一终点，那验证的是均值预测。每个前缀可以只抽一个未来目标、一个噪声和一个时间点，作为期望的 Monte Carlo 估计；对照组按同一目标采样及预算训练。

这是未来物品的条件边际分布建模，多次采样用于覆盖多个目标。它没有显式建立整份推荐列表内的互补、顺序或联合依赖，不应写成联合 slate/set generation。

## 有限且可归因的实验组

所有行均在新多目标划分重新训练，并保留下一物品 CE。共同的表示目标不在表中重复。

| 组别 | 额外监督 | 要回答的问题 |
|---|---|---|
| A | 无，原下一物品 CE | 新任务的匹配基线 |
| B | 下一物品 CFM | 当前 FM 形式仅改变评测后是否已有覆盖价值 |
| C | 未来分布 CE | 增加未来标签本身可以带来多少收益 |
| D | 未来分布 CFM | 在相同未来标签下，FM 是否提供额外能力 |

C 的辅助 CE 定义为同一未来目标经验分布上的交叉熵，可按与 D 相同的 j 抽样。未来其他已知正例不能被误当负例。C 可用与任务分工匹配的确定性预测头；其输出、容量和参数量必须说明，避免人为构造弱 C。A/B/C/D 的结构若不严格等参数，应披露，后续必要时补容量对照。

比较 B-A 是当前 FM 的增量；D-B 是 FM 内增加未来监督的变化；C-A 是未来监督的非 FM 收益；D-C 是支持 FM 独立贡献的关键。D-C 同时受预测族和解码机制影响，不能仅从这一次比较断言所有 FM 优于所有 CE。

执行顺序控制预算：先完成数据审计和匹配 A/B；若 B 已有充分正向证据，再决定是否无需改变训练目标即可完成新增研究方向。若仍需多目标训练，补 C/D。只用 seed2024；正式论文最终方案和关键对照再多种子，不自动扩大矩阵。

## 读出、指标与成本

- 每人最终展示相同 K 个不同物品，padding 不进入目录。候选覆盖实验也固定唯一候选数。增加样本或池子大小不单独归因于 FM。
- 主指标使用未来集合 Recall@K 和多正例 NDCG@K。另按未来步长报告相关性，检查收益是否仅来自牺牲第一个目标。
- 若声称“多样”，额外报告列表类别/语义多样性，并报告命中的真实目标覆盖了哪些类别；类别覆盖可以是预注册的辅助诊断，不伪装成公认标准指标。随机推荐的类别分散不能作为有效多样性证据。
- 同一新任务 checkpoint 可在同一预测时点评价 y1 和整个未来集合。但旧 LOO 主表仍按自身协议评价，不能混合两种 checkpoint 选择结果。
- CE top-K 是必须保留的确定性基线；CE 类别采样和未运输先验可以作为无需新增训练的诊断。固定采样数时不等于等成本，另报告 NFE、目录检索与实际延迟。
- 当前 FM 默认 32 样本×4 步为 128 次速度查询。采样均值前应在物品概率空间聚合；不能先平均 endpoint embedding 再以单查询代替整个分布。
- 若改变为逐样本检索后合并，需要固定统一规则，并把改变解码与改变训练分开。不得用真实未来标签做样本选择、融合、去重配额或重排序。
- 不采用“全目录 CE top-K 扩池后再按相同 CE 分数取 K”作为 FM 改善机制：若原 CE top-K 全保留，重排会回到原列表。本地既有报告已经核对这个问题。
- 新方向按预先固定的多目标 validation 主指标选模，旧 LOO 仍按原规则。完成探索、冻结方案后再一次性做最终 test。

## 论文结论的边界

可以预先提出：下一物品相关性和未来多需求覆盖是不同评价对象；研究 CE 与 FM 的目标分工是否有助于兼顾二者。

只有获得对应证据后才可以写：FM 在相同未来监督、固定列表大小下，优于确定性分布预测/多兴趣基线；或者在基本保留下一物品性能的同时改善未来覆盖。“基本保留”需要预先设定容忍范围并最终多种子验证，不能由不显著自动推断等效。

若仅 C、D 同时优于 A，而 D 不优于 C，贡献应落在任务监督/整体框架，不把收益独归 FM。若 D 在新增任务依然无收益，继续检查目标表示、场拟合及解码；结论仍不能归咎于 benchmark，更不能根据 test 选协议。

本轮完成的是研究定位、近邻文献核对和实验协议设计。没有新增任何性能数字。
