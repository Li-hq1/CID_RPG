# 2026-10-28 项目整理

项目名称统一为 UGRec，保留磁盘路径 `/home/haoquan/CID_RPG`。用户确认本次将旧 bridge、normalization 等结构的联合训练实验完整归档，不恢复缺失的历史实现。

## 版本边界

- v1：PCA 输入，Transformer/HSTU 生成条件，Rectified Flow 连续生成，多次独立采样与候选聚合。
- v2：保留 v1 推荐骨架与 PCA 对照，加入独立训练的 Geometry AE、几何诊断与消融，AE 冻结后输出推荐特征。
- v3：自带所需 AE 与推荐模块，实现交替联合训练、可选 AE-only 对比学习和 Optuna；本版的 `train.py` 为本地 PCA 对照，正式联合训练入口是 `python -m joint_training`。

- 不改模型权重键，保留 TigerDiff 内部类名与兼容导入。新实验名称使用 UGRec。

- 未启动完整训练或重跑正式指标；真实缓存小样本检查与单元测试结果见 [验收记录](验收记录.md)。
